# 돌 추격 무적 연습

2026-11-25 기준, `main 8419529` 위 `feature/gameplay-restore-expansion` 미커밋 작업본을 설명한다.

[`BoulderPractice/돌추격_무적연습.pyw`](../BoulderPractice/돌추격_무적연습.pyw)를 더블클릭하거나 프로젝트 루트에서 `python -m BoulderPractice.boulder_practice`로 실행한다. 본게임 [`SourceCode/main.py`](../SourceCode/main.py)와 분리된 **독립 1인칭 연습**이다. Python·pico2d·transitions와 기존 복도 렌더러·원본 재질을 사용한다. 기본 창 크기는 1440×900이며 `--width`와 `--height`로 지정할 수 있다.

먼지는 `sprite/traps/boulder_chase_v1`, 장애물과 출구는 `sprite/traps/boulder_room_v2/catalog.json`의 에셋을 사용한다. 장애물·출구 카탈로그가 없으면 충돌 범위와 출구 폭에 맞춘 석재 도형을 그린다.

| 조작 | 동작 |
| --- | --- |
| WASD / 방향키 | 현재 시선 기준 전진·후진·좌우 이동 |
| Shift + 이동 | 달리기. 스태미너 소모 |
| 마우스 좌우 이동 | 수평 360° 시선 회전. 뒤쪽도 직접 돌려 확인 |
| 출구 근처에서 F | 측면 출구 통과. 출구 위치에서 벽 쪽으로 이동해도 통과 |
| R | 처음부터 재시작. 스태미너·접촉 횟수 초기화 |
| Esc / 창 닫기 | 종료 |
| F10 | 현재 화면을 `output/boulder_practice/manual.png`에 저장 |

Q 후방 보기는 제거했다. W를 누른 채 시선을 돌리면 이동 방향도 현재 시선을 따른다. 다른 창으로 전환하면 연습을 일시 정지하고 이동 입력과 마우스 캡처를 해제한다. 창에 포커스와 마우스가 돌아오면 다시 진행하며, 성공·종료 때도 캡처를 해제한다. 시작·포커스 복귀 때 SDL 텍스트 입력과 Windows IME 연결을 해제한다.

## 테스트 규칙

- 연습 시간 5초에 돌이 출발한다. 준비 중에도 이동할 수 있다.
- 기둥과 석재 더미는 실제 이동을 막는다. 옆으로 돌아가야 한다.
- 걷기 목표 속도는 2.55m/s, 달리기는 4.70m/s, 돌의 최고 속도는 3.70m/s다. 스태미너는 100에서 시작하며 달려 이동하면 초당 최대 25를 쓴다.
- 스태미너는 자동 회복하지 않는다. 0이 되면 걸어서 이동하며, R로 재시작하면 100으로 돌아온다.
- 왼쪽 약 46m의 좁은 출구와 오른쪽 약 52m의 넓은 출구로 통과할 수 있다.
- **돌에 닿아도 사망하지 않는다.** 체력은 100 고정이며 접촉 횟수와 경고만 표시한다. 돌은 위치·속도를 유지하고 플레이어를 지나 앞으로 계속 굴러간다. 뒤로 재배치하거나 새 돌을 생성하지 않는다. 플레이어 위치와 스태미너도 유지한다.
- 한 번 겹쳐 있는 동안 접촉은 1회만 센다. 완전히 떨어진 뒤 다시 닿으면 새로운 접촉으로 센다. R 재시작 시에는 처음 돌과 접촉 기록을 초기화한다.
- 거리 표시는 돌이 뒤에 있으면 후방 여유, 겹치면 통과 중, 앞서가면 앞쪽 돌까지의 여유를 보여 준다. 마우스로 뒤를 돌아보면 돌의 실제 접근·회전을 확인할 수 있다. 돌은 시선과 무관하게 복도 진행축을 따라 움직이며 통과한 뒤에도 계속 전진한다. 코스 끝을 벗어난 돌은 화면에서 제외한다.
- 성공하면 소요 시간·돌 접촉 횟수·잔여 스태미너를 표시한다. R로 다시 도전한다.

이 코스는 본게임의 시간대 전환·함정 숏컷과 별개다. 독립 연습은 **후방 추격·무적·측면 출구**이고, 본게임은 **여섯 줄 교차 경사로·돌 접촉 즉사·정상 완주 C→D 길 단축**이다. 본게임에서 취소·시간대 전환만 정확한 입구로 복귀한다. 두 모델 모두 마우스 수평 360°·시선 기준 WASD를 사용하지만 함정 구조·실패·출구 규칙은 다르다. 본게임 규칙은 [PRD](PRD.md)를 따른다.

## 검증

저장소 루트에서 실행한다.

```powershell
python -m TestCode.check_boulder_practice
python -m TestCode.check_first_person_movement
python -m BoulderPractice.boulder_practice --smoke --width 1280 --height 800
python -m TestCode.check_corridor_isolation
python -m TestCode.check_visuals
```

규칙 검사는 준비 시간·돌의 연속 전진·중복 접촉 방지·재접촉·무적·스태미너 0 보행·장애물 우회·양쪽 출구와 6개 기준 경로를 확인한다. 시선 이동 검사는 칼날방·본게임 교차 돌방·독립 연습의 회전 직후 이동 방향과 대각 속도를 확인한다. SDL 스모크는 W·Shift·마우스 상대 이동·R·F, 포커스 전환·캡처 해제와 Q를 눌러도 시점이 바뀌지 않는 동작을 검사한다. 렌더러 분리·시각 검사는 다른 방 표현과의 독립성, 돌의 연속 회전·접지·시점별 화면을 확인한다.

코딩 실행 보고에서 독립 연습 규칙·시선 이동·Practice 스모크·렌더러 분리·시각 검사는 통과했고 총괄은 독립 모델·프레임을 확인했다. 별도 숨김 Windows HWND 자동 검사에서는 텍스트 입력을 켠 상태의 W 키 5개·문자 5개가 차단 후 키 5개·문자 0개가 됐다. **사람 실키 플레이·소리 청취는 미실행**이며, 기획 채팅은 문서·소스 대조만 수행했다.

기본 출력 위치는 `output/boulder_practice/`다. 규칙 검사는 `rules_checks.json`, 스모크는 `smoke.json`과 시점·입력 확인용 캡처, 시각 검사는 `visuals/`에 결과를 쓴다. 실제 게임 창은 시작 화면을 `launched.png`로 저장하며, `session.json`에 위치·스태미너·접촉 횟수·프로세스 ID와 SDL 창 상태를 1초 간격으로 기록한다. 검사 출력은 실행 전에 `BOULDER_OUTPUT`을 지정해 따로 저장할 수 있다. 이번 코딩·총괄 검수에서 임시물은 삭제했고 기존 `output/` 25개 파일의 목록·해시가 동일함을 보고받았다. 이 문서 작업은 새 검증 파일을 만들지 않았다.

에셋 연결 규격은 [`ASSET_TASKS.md`](ASSET_TASKS.md)를 따른다.

## 돌 표현 개선 v3 — 2026-11-06

돌만 24프레임 평면 시트에서 **연속 회전하는 입체 표면의 2D 투영**으로 교체했다. [`BoulderPractice/boulder_volume.py`](../BoulderPractice/boulder_volume.py)가 거친 구형의 좌표·표면 법선·재질 좌표를 계산하고, pico2d의 SDL_RenderGeometry로 2D 삼각형을 그린다. 3D 엔진이나 레이캐스팅 라이브러리를 추가하지 않는다. 벽·바닥 렌더러는 기존 것을 재사용한다.

- 회전 각도는 이동 거리 ÷ 반지름으로 연속 계산한다. 시트를 초당 약 10장 바꾸던 계단식 움직임을 없앴다.
- 좌우 이동과 마우스 시선 회전에서도 같은 표면을 다른 시점으로 투영한다. 앞서가는 돌과 뒤에서 다가오는 돌의 회전 방향이 실제 월드 좌표로 이어진다.
- 완전한 공 모양에 넓고 얕은 요철을 추가하고, 회전할 때마다 가장 낮은 지점이 바닥에 닿도록 높이를 맞춘다.
- 바닥 위의 부드러운 접지 그림자와 밑면 음영을 더하고, 회전하는 표면의 법선과 시점에 따른 조명을 계산한다.
- 큰 먼지 그림 한 장 대신 접지 부근에서 작은 먼지와 잔돌이 뒤에 남는 표현을 사용한다.
- 새 재질은 `sprite/traps/boulder_volume_v2/stone_material.png`다. 큰 균열이 보여 회전 방향을 알아보기 쉽도록 만들었다. 구형 돌 시트는 제거했고 먼지는 별도 유지한다.

시각 검사는 현재 돌의 연속 회전·접지·좌우 시점·전후방 근접 교차와 그리기 시간을 확인한다. 기본값은 SDL 더미 드라이버의 소프트웨어 렌더링이다. `--native`로 실행하면 SDL이 시스템에서 선택한 렌더러와 프레임 그리기·제출 시간을 보고한다.
