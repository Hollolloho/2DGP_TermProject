# PRD - 초보자를 위한 미로 탈출 안내서

- 문서 버전 0.18
- 최종 수정일 2026-11-15 (Asia/Seoul)
- 최신 게임 규칙, 개발 범위와 검증 기준을 정리한다.
- 개발 형태: 개인 개발 / PC 1인 플레이
- 개발 환경: Python, pico2d, transitions
- 현재 빌드는 쿼터뷰 탐색, 시간대별 변형, 수호자 전투, 마우스 미로 퍼즐의 예약 개방, 정면 고정 1인칭 칼날방을 지원한다. 돌 추격은 별도 무적 연습에서 실행할 수 있다.

## 1. 게임 개요

제한된 시야의 쿼터뷰 미로에서 퍼즐로 다음 시간대의 길을 준비하고, 체력과 스태미너를 관리하며 중앙 탈출구에 도달하는 미로 탐색·퍼즐 액션 게임이다.

| 항목 | 규칙 |
| --- | --- |
| 제목 | 초보자를 위한 미로 탈출 안내서 |
| 목표 | 미로 중앙 로프에 접근해 F를 누르면 CLEAR |
| 실패 | 일반 미로와 칼날방에서 체력 0. 굴러오는 돌에 깔릴 때의 즉사는 통합 후 구현 |
| 시간 구조 | 낮 → 밤 → 새벽 → 낮 반복. 새벽 종료 자체는 실패 조건이 아님 |
| 플레이 시간 | 한 판 약 3~5분을 초기 테스트 목표로 사용. 전체 강제 제한시간은 없음 |
| 화면 | 일반 미로는 비스듬히 내려다보는 쿼터뷰 2D, 함정방 내부는 정면 고정 1인칭 |

이 문서의 **확정 규칙**은 구현 기준이다. **테스트 기본안**은 검증하며 조정하고, **후속 결정**은 해당 기능 구현 전에 정한다. 목표 기획과 현재 구현 상태는 구분하며, 구현·에셋 준비·미완료 범위는 11절에 정리한다.

## 2. 핵심 재미와 플레이 흐름

- 국소 미리보기로 닫힌 문과 다음 시간대에 열릴 모습을 확인하고, 마우스 미로를 풀어 개방을 예약한다.
- 다음 시간대에 열린 길을 직접 이용한다. 여러 경로 중 하나를 고르는 퍼즐은 후속 구현이다.
- 위험 선택: 일반 통로의 이동·전투, 함정형 숏컷의 위험, 샘물 접근의 이득을 비교한다.
- 자원 관리와 탐색: 체력·스태미너를 배분하고 시간대별 지형을 학습한다.

기본 흐름은 **탐색 → 상태·남은 시간 확인 → 퍼즐로 개방 예약 → 이동과 전투 → 시간대 전환 → 열린 경로 이용**이다. 중앙에 도달하지 못하면 다음 시간대로 계속 진행한다.

## 3. 미로·시간대·시작 위치

### 3.1 기본 미로와 경로

- 31×23 격자에서 시드로 낮 지형을 만들고, 낮 지형의 통로 3곳을 닫고 벽 3곳을 열어 밤과 새벽의 각 배치를 만든다. 한 회차에서 세 배치를 반복 사용하며 열린 퍼즐 통로는 계속 적용한다.
- 미로 연결·이동·충돌·숏컷·방문 지도는 같은 격자를 사용한다. 같은 시드의 새 회차는 스폰 선정에 회차 번호를 반영한다.
- 시간대별 변형에서 주요 지점과 칼날방 입·출구의 3×3 주변을 보존한다. 시간대에 따라 입구 위치와 유형을 바꾸는 배치는 6절의 목표다.
- 일반 통로만으로도 정상 탈출 경로가 있어야 한다. 숏컷은 일부 우회만 줄이고 탈출구나 마지막 구간으로 바로 이어지지 않는다.
- 순환 통로와 갈림길을 포함하고, 단순 오른손 이동만으로 쉽게 해결되지 않는 구조를 목표로 검증한다.
- 최종 맵 크기와 숏컷의 거리 이득 수치는 플레이테스트로 정한다.

### 3.2 새 회차

- 새 게임과 사망 후 재시작은 새 회차다. 안전한 통로 후보에서 랜덤 스폰한다.
- 벽·몬스터·함정과 겹치거나 탈출구 바로 옆인 위치는 제외하고, 모든 후보에서 탈출 가능성을 확인한다.
- 시작 시간대는 첫 회차 낮, 다음 밤, 다음 새벽, 이후 다시 낮 순이다. 이전 판의 종료 시간대와 별도로 관리한다.
- 새 판은 체력·스태미너 각 100에서 시작한다. 샘물 사용, 횃불 획득, 퍼즐 진행·예약·개방, 수호자 상태와 방문 지도를 초기화한다.
- 시작 시간대 순번은 실행 중 유지한다. 앱을 다시 시작하면 낮부터 시작하며, 실행 간 저장은 후속 검토 항목이다.

### 3.3 전환 연출과 안전

- 낮·밤·새벽은 각각 60초다. HUD에 현재 시간대와 남은 시간을 표시하고, 5초 전 화면으로 예고한다. 오디오를 사용할 수 있으면 기존 효과음도 함께 재생한다.
- 전환 시작 시 미완료 퍼즐을 초기화하고, 칼날방에서는 저장한 입장 위치로 복귀한다. 쿼터뷰는 진동과 벽 타일의 이동·페이드로 변형을 표현한다.
- 0.6초 변형 중 이동과 세계 진행을 멈춘다. 0.3초 지점에 지형·충돌·시간대별 지도를 한 번 교체하며 HUD 위치는 고정한다.
- 다음 지형에서 플레이어 몸 전체가 들어가면 좌표를 유지한다. 막히면 이전 통로를 따라 가까운 공통 안전 칸으로 옮긴다.
- 연출 중 재시작하면 이전 판의 예약 연출을 취소한다. 시간대 길이·예고·연출 강도는 테스트한다.

## 4. 화면 표현·조작·애니메이션

### 4.1 화면 구성

| 구간 | 표현·플레이 |
| --- | --- |
| 일반 미로 | 쿼터뷰 2D로 탐색·전투·퍼즐 진행. 방문 지도는 같은 격자 데이터를 사용 |
| 함정방 내부 | 벽·바닥·천장 재질을 원근 투영하고 함정·사물을 겹쳐 그리는 정면 고정 1인칭 |
| 통과·시간대 전환 | 일반 미로의 쿼터뷰로 복귀. 통과 시 연결 통로, 전환 시 입장 직전 외부 위치 사용 |

일반 미로는 쿼터뷰 바닥·벽과 사물 스프라이트로 구성한다. 새 플레이어는 페인팅 스타일의 2D 스프라이트를 기준으로 하며, 엄격한 도트 팔레트로 제한하지 않는다. 벽·바닥 원본 재질은 색상·질감 기준으로 재사용하되 지형·입구·소품·수호자는 새 시점과 크기에 맞춰 준비한다. 플레이어는 단검, 기본 몬스터는 낡은 갑옷의 미궁 수호자를 기준 외형으로 삼는다. 기존 불꽃·검격 효과는 크기·방향·타이밍을 맞춰 재사용한다.

함정방의 벽·바닥·천장은 방 좌표에 고정한 평면에 원본 재질을 입히고 이동에 따라 원근 투영한다. 칼날 등 평면 사물은 깊이에 따른 크기·가림을 처리한다. 돌은 연속 회전하는 입체 표면을 계산해 2D 삼각형으로 투영하며 접지 그림자를 함께 표시한다. 돌 표현은 별도 연습에서 구현됐고 본 게임 연결은 후속 작업이다. 별도 3D 엔진·레이캐스팅을 도입하거나 장소마다 완성 복도 이미지를 만들지 않는다. 삭제 대상인 구형 벽·바닥·천장 시트의 존속을 전제로 하지 않는다.

- 미로 규칙·이동·충돌은 기존 2D 격자로 유지하고 화면 좌표만 쿼터뷰로 변환한다. 캐릭터의 발 기준점과 지형 높이·깊이에 맞춰 앞뒤 순서를 정하고 벽 뒤 사물과 플레이어의 가림을 처리한다.
- 진행 방향과 관계없이 플레이어를 중심으로 격자 좌표 기준 원형 시야를 적용한다. 시제품의 반경은 기본 5.5칸, 횃불 획득 후 7칸이다. 반경 밖과 벽에 막힌 칸은 현재 시야에서 제외하며, 앞을 막는 벽 자체는 보인다. 전에 확인한 지형은 현재 시야 밖에서 어둡게 표시한다. 범위·밝기·횃불 지속 및 소모 수치는 플레이테스트에서 조정한다.
- 새로 보이는 칸과 횃불의 조명은 약 0.20초에 걸쳐 밝기가 바뀐다. 지형·캐릭터에는 nearest 필터를 적용하며, 플레이어 프레임은 64×64, 발 기준점은 (32, 54), 바닥 타일은 64×32를 쓴다. 기본 창은 1280×800이며 쿼터뷰와 HUD는 640×400, 칼날방은 1280×800 원근 화면으로 그린다.
- HUD·퍼즐 UI·전체 지도는 시점과 별도다. 체력·시간·판 기록은 두 시점에서 공유한다.

### 4.2 조작키

| 행동 | 입력 |
| --- | --- |
| 일반 미로 이동 | W / A / S / D로 통로 방향 이동. 화면에서는 각각 북서 / 남서 / 남동 / 북동 |
| 달리기 | 이동 + Shift |
| 회피 | Space 동작은 후속 구현 |
| 기본 공격 | 일반 미로에서 마우스 좌클릭 한 번으로 화면 8방향 단검 2연타 |
| 퍼즐·샘물·횃불·함정방·탈출구 | 접근 후 F |
| 마우스 미로 | 출발점이나 남은 커서 위치에서 좌클릭을 누른 채 도착점까지 선 잇기 |
| 지도 열기·닫기 | M |
| 취소·닫기 | Esc로 지도·퍼즐을 닫거나 칼날방 입장 위치로 복귀. 일반 미로에서는 창 닫기 |
| 함정방 이동 | W/S 전진·후진, A/D 좌우 이동, Shift 달리기 |
| 새 회차 | R |
| 검사용 전체 시야 / 화면 저장 | V / F10 |

일반 미로에서는 각 이동 키를 기존 격자의 한 통로 방향에 대응시킨다. 두 축의 키를 함께 누르면 격자 대각선으로 이동한다. 화면 상·하·좌·우 입력은 각각 W+D / A+S / W+A / S+D이며, 같은 축의 반대 키는 상쇄된다. 이동 속도는 화면에 투영된 지면 거리를 기준으로 계산한다.

### 4.3 시점 전환과 중앙 탈출

- 함정방 진입 전 외부 좌표·방향을 저장하고 짧은 암전으로 1인칭으로 전환한다.
- 두 시점의 입력·그리기는 분리하되 자원·시간·판 기록을 복제하지 않는다. 함정방은 자유 시점 회전을 사용하지 않는다.
- 통과 시 연결된 외부 통로로, 시간대 전환 시 저장한 입장 직전 위치로 복귀한다. 주변 통로 보존은 7절과 같다.
- 중앙 탈출구의 로프에 접근해 F를 누르면 바로 CLEAR를 표시한다. 로프 상승과 암전 연출은 후속 구현이다.

### 4.4 플레이어 애니메이션

`sprite/quarter/player_explorer_attack_v2/`의 `explorer.png`, `explorer.json`과 `moving-attack.png`를 사용한다. 대기·걷기·공격은 8방향을 지원하며 달리기는 대각선 4방향 클립을 사용한다.

| 상태 | 준비된 구성 | 연결 기준 |
| --- | --- | --- |
| 대기 | 대각선 각 4프레임, 상하좌우 각 1프레임 | 방향별 지정된 한 프레임에 멈춤 |
| 걷기 | 대각선 각 8프레임, 상하좌우 각 16프레임 | 충돌 처리 후 실제 이동 거리로 주기를 진행 |
| 달리기 | 대각선 각 8프레임 | Shift와 스태미너에 연결. 상하좌우 이동에는 대응하는 대각선 클립 사용 |
| 공격 | 화면 8방향, 방향별 13프레임·750ms, 자동 2연타 | 네 번째와 아홉 번째 프레임 시작(233ms, 466ms)의 JSON `hit` 이벤트에서 각각 타격 판정 |
| 피격 | 대각선 각 4프레임 준비 | 체력·안내를 갱신하고 칼날 피격 시 화면을 붉게 표시. 플레이어 전용 피격 모션은 후속 연결 |

- 방향·프레임별 재생 시간·발 기준점은 에셋의 JSON을 기준으로 한다. 화면상의 그림 크기를 충돌 범위로 사용하지 않는다.
- 단일 키로 통로를 걷거나 달릴 때는 화면상 이동 방향에 대응하는 기존 대각선 클립을 재생한다.
- 단검 베기의 방향은 공격 시작 시 고정한다. 각 `hit` 시점에 시작 방향 앞쪽 1.8칸 이내에서 벽에 가려지지 않은 수호자에게 타격 1회를 적용한다. 수호자는 3회 타격으로 처치한다. 검격 효과는 각 타격에 맞춰 현재 공격 프레임의 칼끝을 따라간다.
- 이동 중 공격은 고정된 방향의 상체 공격과 이동 거리로 재생하는 하체를 함께 그린다. 공격 방향을 등지고 이동하면 하체 주기를 역재생하며, 횃불 불꽃은 공격 프레임의 가방 부착점을 따라간다.
- Space 회피는 규칙·동작을 후속 구현하며 위 5종에 회피 전용 애니메이션이 준비됐다고 간주하지 않는다.

## 5. 다음 시간대 변경 퍼즐

### 5.1 공통 규칙

- 모든 퍼즐은 현재가 아닌 **바로 다음 시간대**의 미로에 영향을 준다. 낮 퍼즐은 다음 밤, 밤 퍼즐은 다음 새벽, 새벽 퍼즐은 다음 낮에 적용한다.
- 완료 즉시 개방을 예약하고 바로 다음 전환에 처음 개방한다. 현재 미로는 즉시 바뀌지 않는다.
- 마우스 미로 오른쪽의 3×3 미리보기에서 현재 닫힌 문과 다음 시간대에 열린 지형을 확인한다.
- HUD는 풀이 가능, 다음 시간대 개방 예정, 개방 완료 상태를 표시한다. 예약 중에는 문이 닫혀 있고, 다음 지형으로 교체하는 시점부터 통과할 수 있다.

### 5.2 퍼즐 3종

| 유형 | 조작·결과 | 상태 |
| --- | --- | --- |
| 마우스 미로 | 출발점에서 좌클릭을 누르고 통로를 따라 도착점까지 선 잇기 | 구현. 난도는 추가 검증 |
| 통로 연결 | 통로 조각을 클릭해 회전하고 입구와 출구 연결 | 계획. 조각 수, 구성, 해법 수와 난도 검토 |
| 숏컷 경로 선택 | 미리 만든 경로 2~3개를 비교해 하나를 선택·확정하고 다음 시간대에 적용 | 계획. 후보별 거리·위험 차이와 적용 위치 검토 |

가시 범위에 문이 있고 예약·개방 전이면, 낮·밤·새벽 모두 문 양쪽의 접근 칸 중심 0.75칸 이내에서 F로 열 수 있다. 사각 커서가 통로를 따라 이동하고, 지나온 칸은 금빛으로 이어지며 현재 커서의 칸은 더 밝다. 벽과 모서리 가로지르기는 막고, 통로로 돌아와 이어 그릴 수 있다. 직전 통로를 되짚으면 선과 금빛이 함께 줄어든다. 도착 칸에 들어가면 즉시 완료한다.

숏컷 경로 선택은 통로 칸을 자유롭게 제작하는 방식이 아니다. 선택한 후보와 개방 예약을 함께 저장한다. 후보는 실제 통행 가능해야 하며, 항상 최단 후보만 유리해지지 않도록 자원·위험·이후 이동 계획을 함께 검토한다.

### 5.3 세계 진행·피격·전환

- 퍼즐 중에도 시간대 타이머와 수호자 추적·공격이 진행된다. 수호자에게 피격되면 퍼즐 UI를 즉시 닫고 드래그를 해제하며, 그때까지 그린 경로는 보존한다.
- 마우스 버튼을 놓거나 창 포커스를 잃으면 입력만 해제한다. Esc로 닫거나 피격된 뒤에도 같은 시간대에 F로 다시 열어 마지막 커서 위치부터 이어 그릴 수 있다.
- 시간대 전환을 시작하면 미완료 경로를 초기화한다. 피격으로 이미 닫힌 풀이도 초기화한다.
- 완료한 퍼즐의 예약은 다음 지형 교체에 적용한다. 여러 퍼즐의 예약 수정과 충돌 우선순위는 추가 유형 구현 시 정한다.

## 6. 숏컷과 무작위 배치

| 경로 | 이용 방식 |
| --- | --- |
| 일반 통로 | 상대적으로 긴 이동 중 몬스터와 전투하거나 회피 |
| 퍼즐형 숏컷 | 외부 위협 속에서 퍼즐을 풀어 다음 시간대 개방 준비 |
| 함정형 숏컷 | 입구 퍼즐 없이 진입해 내부 함정 돌파 |

- 칼날방 입구·도착 지점은 회차마다 배치한다. 유효 후보가 있는 회차에는 마우스 미로 문 1곳도 배치한다. 세 시간대에서 배치한 위치를 유지한다.
- 퍼즐형 숏컷을 연 뒤에는 같은 회차의 모든 후속 시간대에서도 그 문을 통과할 수 있다. 시간대별 대응 입구와 개방 기록의 연동은 후속 배치 확장 항목이다.
- 새 판마다 숏컷 위치·퍼즐형/함정형·세부 유형의 무작위 배치를 목표로 한다. 시간대별 3곳씩 총 9곳이 기본안이며 유형별 개수 보장은 미정이다.
- 새로 열리는 입구와 이용 가능한 함정형 입구는 플레이어 근처의 유효 후보에서, 이후 대응 입구는 기존 입구 근처에서 고른다. 거리 기준과 후보 부족 처리는 후속 결정이다.
- 확장 배치에서는 후보 추출 후 연결성과 안전성을 검증하고 실패 시 재추첨하거나 안전한 사전 배치를 사용한다. 현재는 정해진 기준을 만족하는 문 후보를 탐색하며, 후보가 없으면 퍼즐 문을 배치하지 않는다.
- 일반 탈출 경로, 국소 이득, 통과 후 탐색 거리, 충돌·방 크기, 스폰 안전성, 복귀 지점·주변 통로 보존과 여러 숏컷 동시 개방을 검증한다.
- 새 회차를 시작하면 스폰을 다시 정하고 해당 회차의 숏컷 배치와 개방 기록을 초기화한다.

## 7. 함정방

| 유형 | 규칙·상태 |
| --- | --- |
| 굴러오는 돌 | 독립 무적 연습을 실행할 수 있다. 본 게임의 갈림길과 돌 충돌 즉사는 통합 단계에서 구현 |
| 움직이는 칼날 | 본 게임에 구현. 움직이는 칼날 3개를 지나 9m 통로를 통과하며, 피격당 피해 20과 짧은 후퇴가 적용된다. 체력이 0이면 실패 |

- 칼날방 HUD는 체력·스태미너·시간대·남은 시간·진행률·출구까지 남은 거리를 표시한다. 시간대 전환이 가까워지면 입장 전 위치로 복귀한다는 안내를 표시한다.
- 진입 시 외부 위치와 이동 방향을 저장한다. Esc를 누르거나 시간대 변형을 시작하면 저장 위치로 복귀한다. 통과하면 외부 B 지점에 도착하고 방문 지도에 기록한다.
- 세 시간대에서 A 입구, B 지점과 각각의 3×3 주변 지형을 보존한다. 복귀한 뒤에는 일반 미로의 수호자 규칙이 적용된다.
- 칼날방에 다시 들어갈 때 내부 진행과 속도를 초기화한다. 추가 함정은 입구에서 위험을 예고하고 회피 기회를 알아볼 수 있게 설계한다. 추가 함정의 전환·충돌 우선순위와 복귀 보상은 후속 검토 항목이다.

[`BoulderPractice/boulder_practice.py`](../BoulderPractice/boulder_practice.py)는 5초 뒤 돌 출발, 장애물 우회, 측면 출구, 달리기·스태미너 소모와 돌의 연속 회전을 구현한 독립 연습이다. 돌 접촉 횟수를 집계하고 Q로 뒤를 볼 수 있다. 본 게임의 자원·시간대·입출구·강제 복귀와 즉사 처리는 통합 이후 구현한다.

## 8. 체력·스태미너·회복

- 체력과 스태미너의 최대값은 각각 100이다. 체력은 피해로 감소하고, 0이면 실패한다. 체력 자연 회복과 시간대 전환 자동 회복은 없다.
- 스태미너는 새벽에만 세계 시간 기준 초당 8씩 회복한다. 일반 미로에서 달려 실제 이동한 경우와 칼날방에서 Shift로 전후 이동할 때 초당 18씩 차감한다. 스태미너가 부족하면 걷기와 퍼즐 조작을 계속할 수 있다.
- 샘물은 회차당 1곳이다. F를 누르면 체력 35를 최대값까지 회복한다. 사용 상태는 세 시간대가 공유하고, 물이 남았는지 고갈됐는지 그림을 바꿔 표시한다.
- 현재 단검 공격의 스태미너 소모는 0이다. 회피·공격 비용, 샘물 추가 배치와 회복량 조정은 후속 검토 항목이다.

## 9. 방문 지도·단서·HUD

- M키로 현재 시간대의 방문 지도를 연다. 직접 밟은 칸과 자신의 위치를 표시하고, M 또는 Esc로 닫는다. 시간대가 바뀌면 해당 시간대의 방문 기록을 사용한다.
- 칼날방 입구를 시야에서 발견하면 A, 통과한 뒤에는 도착 지점 B를 지도에 표시한다. 퍼즐 문과 접근 칸이 시야에 들어오면 해당 접근 칸에 P 표식을 표시한다. 퍼즐 개방 상태는 HUD에서 확인한다.
- 지도를 보는 동안 이동·공격·상호작용 입력을 막고 세계 시간과 수호자 추적·공격은 계속 진행한다. 공격 예고 시 지도에 경고 문구를 표시하며 피격 때 지도가 닫힌다.
- 중앙 탈출구는 미로에서 로프로 표시한다. 중앙 방향 소리, 바닥·벽 문양과 청각 대체 표시는 후속 검토 항목이다.
- HUD에 체력·스태미너·횃불 획득 여부·시간대·남은 시간·변형 예고를 표시한다. 퍼즐은 풀이 가능, 예약, 개방을 표시하며 미리보기는 퍼즐 패널 오른쪽에 둔다. 성공·실패 화면에서 R로 새 회차를 시작한다.

## 11. 구현 구조와 확인 범위

### 11.1 구현 구조

- 기본 입력 처리·update(dt)·draw 루프를 사용하며 별도 엔진·범용 프레임워크를 제작하지 않는다.
- 현재 게임 FSM은 탐색·퍼즐·함정방·변형·성공·실패를, 플레이어 FSM은 대기·걷기·달리기·공격을 관리한다. 회피와 플레이어 피격 상태는 후속 구현이다.
- 게임·플레이어에 각각 transitions Machine을 사용한다. 이벤트 시 상태를 전이하며 매 프레임 새로 생성하지 않는다.
- [`SourceCode/mouse_maze.py`](../SourceCode/mouse_maze.py)는 마우스 미로 입력·경로·벽 판정을 관리한다. 게임 상태가 성공·예약·전환을 처리하고 화면 코드가 경로와 미리보기를 그린다.
- 탐색·퍼즐 중 세계를 갱신하고 변형 중 잠시 멈춘다. 화면 표현과 2D 규칙·충돌 데이터를 분리한다.
- 현재 [`SourceCode/main.py`](../SourceCode/main.py)는 실행 진입점, [`SourceCode/game_framework.py`](../SourceCode/game_framework.py)와 [`SourceCode/play_mode.py`](../SourceCode/play_mode.py)는 루프·입력, [`SourceCode/maze_model.py`](../SourceCode/maze_model.py)는 격자 규칙·상태, [`SourceCode/game_view.py`](../SourceCode/game_view.py)는 화면·HUD, [`SourceCode/trap_view.py`](../SourceCode/trap_view.py)는 1인칭 복도 표현을 담당한다. 쿼터뷰 전환에서도 격자 규칙과 화면 표현을 분리한다.
- [`BoulderPractice/boulder_practice.py`](../BoulderPractice/boulder_practice.py)는 독립 돌 연습, [`BoulderPractice/boulder_volume.py`](../BoulderPractice/boulder_volume.py)는 돌의 회전·투영 표현을 담당한다. 돌 함정의 본 게임 통합 시 자원·시간·판 기록을 공유할 계획이다.

- 시간대 전환은 수호자의 공격 예고를 취소하고 감지 기록을 초기화한다. 다음 지형에서 현재 위치나 이동 중인 칸이 막히면 수호자의 시작 칸에서 도달할 수 있고 플레이어와 1.25칸보다 멀리 떨어진 통로로 옮긴다.
- 삭제 파일 참조와 구형 재패킹·비교 도구를 제거했다. 시제품은 새 카탈로그에서 일반 미로 지형과 사물 에셋을 읽는다. 캐릭터와 벽은 지면 기준점에 따라 가려진다.
- 지형·소품·숏컷·수호자·돌방 사물의 경로와 프레임 규격은 [`ASSET_TASKS.md`](ASSET_TASKS.md)에 기록한다. 파일 및 규격은 [`TestCode/checks_assets.py`](../TestCode/checks_assets.py)에서 확인하고, 화면·입력 연결은 아래 SDL 검사에서 확인한다.

### 11.3 확인 범위

- `python -m TestCode.checks_assets`는 에셋과 프레임 규격을 확인한다. `python -m TestCode.checks_topdown`은 32개 미로의 연결성·충돌·복귀, 원형 시야와 횃불 반경, 벽에 막히는 단검 타격, 자원 규칙을 확인한다.
- `python -m TestCode.checks_phase_changes`는 96개 시작 조건, 288개 지형, 480회 전환과 퍼즐 문 양쪽 진입·피격 재개·예약 개방을 확인한다. `python -m TestCode.checks_gait`는 방향·프레임 간격에 따른 보행 주기를 확인한다.
- `python -m SourceCode.main --smoke`는 화면 없는 SDL 환경에서 통로 방향·두 키 대각선 이동, 렌더링 호출 횟수와 독립적인 보행 주기, 퍼즐 금빛 경로·되짚기·입력 재개, 각 단검 타격과 칼끝 효과, 변형·지도·실제 통과, 칼날방 진입·좌우 이동·복귀를 검사한다.
- 독립 돌 연습은 `python -m TestCode.check_boulder_practice`, `python -m TestCode.check_visuals`, `python -m BoulderPractice.boulder_practice --smoke`로 규칙·표현·입력 경로를 확인한다.
- 기준 커밋에서 위 검사를 통과했다. 실제 플레이 시간과 난도, 통합 성능은 플레이테스트에서 별도로 확인한다.

## 13. 완료·플레이테스트 기준

구현 확인에 사용하는 검사와 범위는 11.3절을 따른다. 다음은 후속 기능도 포함한 플레이테스트 기준이다.

1. 낮→밤→새벽→낮 반복과 새벽 종료만으로 실패하지 않는 규칙이 동작한다.
2. 마우스 미로 양쪽에서 접근하고, 벽 가로지르기 차단, 금빛 경로, 되짚기, 버튼 해제와 재개를 확인한다. 도착 즉시 예약하고 다음 시간대에 미리보기와 같은 문이 열린다.
3. 피격 후 같은 시간대에 이어 풀고, 전환 시 미완료 진행은 초기화한다.
4. 개방 기록은 판 내 유지하며 새 판은 자원·예약·진행·개방·방문 기록을 초기화한다.
5. 체력 자연 회복 없음·샘물 1회 사용·스태미너 새벽 회복·자원 0에서도 기본 진행이 동작한다.
6. 중앙 로프에서 F를 눌러 CLEAR에 도달하고, 체력 0으로 실패한 뒤 R로 재시작한다. 로프 상승·암전과 돌 충돌 즉사는 구현 후 검증한다.
7. 쿼터뷰 화면·충돌·방문 지도가 같은 격자 위치를 사용한다. 플레이어의 방향과 관계없이 주변 원형 시야를 유지하고, 횃불을 얻으면 반경이 늘어난다. 벽 뒤 사물은 시야에 들어오기 전까지 가린다. 함정방에서도 자원·시간을 공유하고 통과/복귀 위치가 일치한다.
8. 지도 중 세계 진행·접근 경고·피격 시 닫기가 동작하고 미방문 지형을 공개하지 않는다.
9. 무작위 배치에 일반 탈출 경로·국소 이득·남은 탐색·스폰·복귀 안전성이 있다.
10. 시간대 전환 시 충돌을 한 번 교체하고, 함정방은 원래 위치로 복귀하며 주변 통로를 보존한다.
11. 화면 안내와 실제 조작이 일치하고 실제 실행 창에서 통합 성능을 확인한다.
12. 타인이 목표·지연 적용·경로 선택 이유를 이해하는지 확인하고, 실제 한 판 시간·반복 횟수·사망 원인·퍼즐 및 통과 시간을 기록해 조정한다.
13. 8방향 대기·걷기·단검 공격과 대각선 4방향 달리기의 방향·발 기준점이 맞는다. 공격 모션, 칼끝 효과, 실제 233ms·466ms 타격을 확인한다. 피격 모션 연결 후 그림 오프셋과 충돌 위치도 검사한다.
