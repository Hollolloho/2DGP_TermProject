# PRD - 초보자를 위한 미로 탈출 안내서

- 문서 버전 0.19
- 최종 수정일 2026-11-25 (Asia/Seoul)
- 최신 게임 규칙, 개발 범위와 검증 기준을 정리한다.
- 개발 형태: 개인 개발 / PC 1인 플레이
- 개발 환경: Python, pico2d, transitions
- 대조 기준: `main 8419529` 위 `feature/gameplay-restore-expansion` 미커밋 작업본. 코딩 모델·SDL 자동 검사 및 총괄 독립 모델·프레임 확인은 통과 보고되었다. 숨김 Windows HWND 입력 차단 자동 검사도 통과했으며 사람 실키 플레이·소리 청취는 미실행이다.
- 현재 소스에는 쿼터뷰 탐색·전투, 시간대별 변형, 퍼즐 3종, 수평 360° 시선의 칼날방·여섯 줄 교차 돌방이 연결되어 있다. 정상 완주 시 연결 출구 이동·중도 입구 복귀는 총괄 모델 검수에서 확인했다. 독립 돌 연습은 무적 모드로 구분한다.

## 1. 게임 개요

제한된 시야의 쿼터뷰 미로에서 퍼즐로 다음 시간대의 길을 준비하고, 체력과 스태미너를 관리하며 중앙 탈출구에 도달하는 미로 탐색·퍼즐 액션 게임이다.

| 항목 | 규칙 |
| --- | --- |
| 제목 | 초보자를 위한 미로 탈출 안내서 |
| 목표 | 미로 중앙 로프에 접근해 F를 누르면 CLEAR |
| 실패 | 체력 0 또는 본게임 여섯 줄 교차 돌방에서 돌 접촉. 독립 돌 연습은 무적 |
| 시간 구조 | 낮 → 밤 → 새벽 → 낮 반복. 새벽 종료 자체는 실패 조건이 아님 |
| 플레이 시간 | 한 판 약 3~5분을 초기 테스트 목표로 사용. 전체 강제 제한시간은 없음 |
| 화면 | 일반 미로와 석판 방은 쿼터뷰 2D, 함정방은 마우스 좌우 이동으로 수평 360°를 보는 1인칭 |

이 문서의 **확정 규칙**은 구현 기준이다. **테스트 기본안**은 검증하며 조정하고, **후속 결정**은 해당 기능 구현 전에 정한다. 목표 기획과 현재 구현 상태는 구분하며, 구현·에셋 준비·미완료 범위는 11절에 정리한다.

### 1.1 목표 기획과 이번 범위

- 확정 목표는 라비린토스의 테세우스가 시작부터 아리아드네의 실을 따라 변화하는 미궁의 중심을 찾고, 미노타우로스를 처치해 날개를 얻어 탈출하는 흐름이다. 실 표시 방식과 무기·몬스터 세부 종류는 미확정이며, 현재 중앙 로프 F CLEAR와 구분한다.
- 최신 확정은 **퍼즐은 막힌 길을 열고, 함정은 통과해 길을 줄이는 것**이다. 본게임 돌방은 여섯 줄 교차 경사로를 유지한다. 정상 완주는 A→B/C→D 연결 출구로 이동하고, 함정 보상 지급·획득 기록과 완주 후 입구 복귀는 사용하지 않는다.
- 이번 작업은 1인칭 입력 복구, 경로 선택 배치 일반화, 함정 숏컷의 안전한 입출구 쌍과 정상 통과·중도 복귀 구분까지다. 새 무기·외형·캐릭터 교체, 보스와 중앙 안내는 범위 밖이다.
- 확정한 빈손 탐험가 레퍼런스와 본편 캐릭터 교체 승인은 별개다. 에셋 작업은 보류하며 현행 단검 캐릭터를 유지한다.

## 2. 핵심 재미와 플레이 흐름

- 국소 미리보기로 닫힌 문과 다음 시간대에 열릴 모습을 확인하고, 마우스 미로를 풀어 개방을 예약한다.
- 다음 시간대에 열린 길을 직접 이용한다. 경로 선택은 두 후보 중 하나를 예약하고, 두 문양 석판 방은 조립한 길을 즉시 걸어 통과한다.
- 위험 선택: 일반 통로의 이동·전투, 함정형 숏컷 통과, 샘물 접근의 이득을 비교한다.
- 자원 관리와 탐색: 체력·스태미너를 배분하고 시간대별 지형을 학습한다.

기본 흐름은 **탐색 → 상태·남은 시간 확인 → 퍼즐로 개방 예약 → 이동과 전투 → 시간대 전환 → 열린 경로 이용**이다. 중앙에 도달하지 못하면 다음 시간대로 계속 진행한다.

## 3. 미로·시간대·시작 위치

### 3.1 기본 미로와 경로

- 31×23 격자에서 시드로 낮 지형을 만들고, 낮 지형의 통로 3곳을 닫고 벽 3곳을 열어 밤과 새벽의 각 배치를 만든다. 한 회차에서 세 배치를 반복 사용하며 열린 퍼즐 통로는 계속 적용한다.
- 미로 연결·이동·충돌·숏컷·방문 지도는 같은 격자를 사용한다. 같은 시드의 새 회차는 스폰 선정에 회차 번호를 반영한다.
- 시간대별 변형에서 주요 지점과 함정방 복귀 지점 주변을 보존한다. 경로 선택과 돌방 입구는 현재 시드·회차의 유효 후보를 탐색하며 조건이 맞지 않으면 생략한다. 시간대별 입구·유형 재배치는 후속 목표다.
- 일반 통로만으로도 정상 탈출 경로가 있어야 한다. 숏컷은 일부 우회만 줄이고 탈출구나 마지막 구간으로 바로 이어지지 않는다.
- 순환 통로와 갈림길을 포함하고, 단순 오른손 이동만으로 쉽게 해결되지 않는 구조를 목표로 검증한다.
- 최종 맵 크기와 숏컷의 거리 이득 수치는 플레이테스트로 정한다.

### 3.2 새 회차

- 새 게임과 사망 후 재시작은 새 회차다. 안전한 통로 후보에서 랜덤 스폰한다.
- 벽·몬스터·함정과 겹치거나 탈출구 바로 옆인 위치는 제외하고, 모든 후보에서 탈출 가능성을 확인한다.
- 시작 시간대는 첫 회차 낮, 다음 밤, 다음 새벽, 이후 다시 낮 순이다. 이전 판의 종료 시간대와 별도로 관리한다.
- 새 판은 체력·스태미너 각 100에서 시작한다. 샘물 사용, 횃불 획득, 퍼즐 진행·경로 선택·예약·개방, 석판 방·함정방 통과, 수호자 상태와 방문 지도를 초기화한다.
- 시작 시간대 순번은 실행 중 유지한다. 앱을 다시 시작하면 낮부터 시작하며, 실행 간 저장은 후속 검토 항목이다.

### 3.3 전환 연출과 안전

- 낮·밤·새벽은 각각 60초다. HUD에 현재 시간대와 남은 시간을 표시하고, 5초 전 화면으로 예고한다. 오디오를 사용할 수 있으면 기존 효과음도 함께 재생한다.
- 전환 시작 시 미완료 퍼즐을 초기화하고, 칼날방·돌방·석판 방에서는 저장한 입장 위치로 복귀한다. 중도 복귀는 반대편 출구 도착으로 기록하지 않는다. 쿼터뷰는 진동과 벽 타일의 이동·페이드로 변형을 표현한다.
- 0.6초 변형 중 이동과 세계 진행을 멈춘다. 0.3초 지점에 지형·충돌·시간대별 지도를 한 번 교체하며 HUD 위치는 고정한다.
- 다음 지형에서 플레이어 몸 전체가 들어가면 좌표를 유지한다. 막히면 이전 통로를 따라 가까운 공통 안전 칸으로 옮긴다.
- 연출 중 재시작하면 이전 판의 예약 연출을 취소한다. 시간대 길이·예고·연출 강도는 테스트한다.

## 4. 화면 표현·조작·애니메이션

### 4.1 화면 구성

| 구간 | 표현·플레이 |
| --- | --- |
| 일반 미로 | 쿼터뷰 2D로 탐색·전투·퍼즐 진행. 방문 지도는 같은 격자 데이터를 사용 |
| 함정방 내부 | 방에 고정한 벽·바닥·천장·함정을 원근 투영. 마우스 좌우로 수평 360° 시선 회전 |
| 석판 방 | 별도 쿼터뷰 방에서 조각 배치·회전 후 연결된 바닥을 직접 보행 |
| 함정방 정상 완료 | 칼날방 A→B, 교차 돌방 C→D의 연결 출구 통로로 이동해 길 단축 |
| 함정방 중도 취소·전환 | 입장 직전의 정확한 외부 좌표·방향으로 복귀. 사망은 실패 |
| 석판 방 통과·중단 | 직접 반대 끝까지 걸으면 외부 반대편 도착. Esc·후퇴·전환은 입장 위치 복귀 |

일반 미로는 쿼터뷰 바닥·벽과 사물 스프라이트로 구성한다. 새 플레이어는 페인팅 스타일의 2D 스프라이트를 기준으로 하며, 엄격한 도트 팔레트로 제한하지 않는다. 벽·바닥 원본 재질은 색상·질감 기준으로 재사용하되 지형·입구·소품·수호자는 새 시점과 크기에 맞춰 준비한다. 현행 플레이어는 단검 캐릭터, 기본 몬스터는 낡은 갑옷의 미궁 수호자다. 이 실행 에셋을 목표 기획의 새 무기·외형 확정으로 간주하지 않는다. 기존 불꽃·검격 효과는 크기·방향·타이밍을 맞춰 재사용한다.

함정방의 벽·바닥·천장은 방 좌표에 고정한 평면에 원본 재질을 입히고 이동에 따라 원근 투영한다. 칼날 등 평면 사물은 깊이에 따른 크기·가림을 처리한다. 돌은 연속 회전하는 입체 표면을 계산해 2D 삼각형으로 투영하며 접지 그림자를 함께 표시한다. 본게임 여섯 줄 교차 돌방은 교차 경사로·돌 궤도를, 독립 후방 추격 연습은 기존 복도를 사용하며 공용 돌 재질·회전 표현을 재사용한다. 별도 3D 엔진·레이캐스팅을 도입하거나 장소마다 완성 복도 이미지를 만들지 않는다. 삭제 대상인 구형 벽·바닥·천장 시트의 존속을 전제로 하지 않는다.

- 미로 규칙·이동·충돌은 기존 2D 격자로 유지하고 화면 좌표만 쿼터뷰로 변환한다. 캐릭터의 발 기준점과 지형 높이·깊이에 맞춰 앞뒤 순서를 정하고 벽 뒤 사물과 플레이어의 가림을 처리한다.
- 진행 방향과 관계없이 플레이어를 중심으로 격자 좌표 기준 원형 시야를 적용한다. 시제품의 반경은 기본 5.5칸, 횃불 획득 후 7칸이다. 반경 밖과 벽에 막힌 칸은 현재 시야에서 제외하며, 앞을 막는 벽 자체는 보인다. 전에 확인한 지형은 현재 시야 밖에서 어둡게 표시한다. 범위·밝기·횃불 지속 및 소모 수치는 플레이테스트에서 조정한다.
- 새로 보이는 칸과 횃불의 조명은 약 0.20초에 걸쳐 밝기가 바뀐다. 지형·캐릭터에는 nearest 필터를 적용하며, 플레이어 프레임은 64×64, 발 기준점은 (32, 54), 바닥 타일은 64×32를 쓴다. 기본 창은 1280×800이며 쿼터뷰와 HUD는 640×400, 함정방은 1280×800 원근 화면으로 그린다.
- HUD·퍼즐 UI·전체 지도는 시점과 별도다. 체력·시간·판 기록은 두 시점에서 공유한다.

### 4.2 조작키

| 행동 | 입력 |
| --- | --- |
| 일반 미로 이동 | W / A / S / D로 통로 방향 이동. 화면에서는 각각 북서 / 남서 / 남동 / 북동 |
| 달리기 | 이동 + Shift |
| 회피 | Space 동작은 후속 구현 |
| 기본 공격 | 일반 미로에서 마우스 좌클릭 한 번으로 화면 8방향 단검 2연타 |
| 퍼즐·샘물·횃불·함정방·탈출구 | 접근 후 F |
| 마우스 미로 | 출발점/남은 커서에서 드래그해 경유지 1→2→3을 거쳐 도착 |
| 두 문양 석판 방 | 좌클릭·드래그로 집기/놓기, R로 선택/들고 있는 조각 90° 회전, WASD 보행 |
| 경로 선택 | 후보 카드 클릭은 임시 선택, 확정 버튼으로 이번 회차의 한 경로 예약 |
| 지도 열기·닫기 | M |
| 취소·닫기 | Esc로 지도·퍼즐 닫기, 함정방·석판 방 입장 위치 복귀. 일반 미로에서는 종료 |
| 함정방 시선 | 마우스 좌우 이동으로 수평 360° 회전. Q 후방 보기 제거 |
| 함정방 이동 | 현재 시선 기준 W/S 전진·후진, A/D 좌우 이동, Shift 달리기 |
| 본게임 돌방 정면 출구 | 여섯 줄을 통과해 정면 출구 접근 후 F 또는 끝까지 보행 |
| 새 회차 | R. 석판 방에서는 조각 회전으로 사용 |
| 검사용 전체 시야 / 화면 저장 | V / F10 |

일반 미로에서는 각 이동 키를 기존 격자의 한 통로 방향에 대응시킨다. 두 축의 키를 함께 누르면 격자 대각선으로 이동한다. 화면 상·하·좌·우 입력은 각각 W+D / A+S / W+A / S+D이며, 같은 축의 반대 키는 상쇄된다. 이동 속도는 화면에 투영된 지면 거리를 기준으로 계산한다.

### 4.3 시점 전환과 중앙 탈출

- 함정방 진입 전 외부 좌표·방향을 저장하고 짧은 암전으로 1인칭으로 전환한다.
- 두 시점의 입력·그리기는 분리하되 자원·시간·판 기록을 공유한다. 칼날방·본게임 돌방·독립 돌 연습 모두 마우스 수평 360° 회전과 시선 기준 WASD를 사용한다. 이동 중 시선을 돌리면 이동 방향도 그 시선을 따른다.
- 포커스가 있는 함정방에서 상대 마우스를 캡처한다. 포커스 상실·방 이탈·종료 시 해제하고 이전 커서 상태로 돌린다. Q 후방 보기는 제거했다.
- 시작·포커스 복귀 때 SDL 텍스트 입력을 중지하고 Windows IME 연결을 해제한다. 코딩의 숨김 Windows HWND 자동 검사에서 텍스트 입력을 켠 상태의 W 키 이벤트 5개·문자 이벤트 5개가 차단 후 키 5개·문자 0개가 됐다. 사람의 한/영 전환·캡처·포커스 복귀 조작 검수와 구분한다.
- 함정방 정상 완료는 연결 출구로 이동한다. Esc·시간대 중단만 저장한 입장 직전 좌표·방향으로 복귀하고 사망은 실패 처리한다. 주변 통로 보존은 7절과 같다.
- 중앙 탈출구의 로프에 접근해 F를 누르면 바로 CLEAR를 표시한다. 로프 상승과 암전 연출은 후속 구현이다.

## 5. 퍼즐 3종

### 5.1 적용 시점

| 유형 | 완료 조건 | 적용 |
| --- | --- | --- |
| 마우스 미로 | 13×9 미로에서 출발→경유지 1→2→3→도착 순서 연결 | 바로 다음 시간대에 문 개방 |
| 두 문양 석판 방 | 입구→두 문양→출구 연결 후 반대 끝까지 실제 보행 | 즉시 외부 반대편 도착. 예약 없음 |
| 숏컷 경로 선택 | `1번 통로`·`2번 통로` 중 하나를 명시적으로 확정 | 바로 다음 시간대에 선택한 문만 개방 |

마우스 미로·경로 선택의 예약은 낮→밤, 밤→새벽, 새벽→낮으로 적용한다. 현재 지형은 즉시 바뀌지 않으며 같은 회차의 후속 시간대에도 개방을 유지한다. 새 회차에서 초기화한다.

### 5.2 유형별 조작과 판정

- **마우스 미로:** 가시 범위의 문 양쪽 접근 칸에서 F로 연다. 좌클릭 드래그로 순서 경유지를 통과하며 도착만으로 성공하지 않는다. 벽·모서리 횡단을 막고 마지막 유효 위치에서 멈춘다. 버튼 해제 후 이어 그리거나 되짚을 수 있으며 경로를 되짚으면 경유 진행도 되돌린다. 경로는 금빛으로 표시하고 오른쪽 3×3 미리보기에서 현재·다음 시간대 문을 비교한다.
- **두 문양 석판 방:** 별도 문에서 F로 진입하고 약 1초 보행 진입 후 4×4 바닥의 직선 3개·모퉁이 6개를 배치한다. 좌클릭·드래그로 집고 놓으며 R로 90° 회전한다. 두 문양은 순서와 무관하게 하나의 연결 경로 위에 있어야 한다. 잘못 놓기·취소는 이전 배치와 회전을 복원한다. 조각을 들고 있으면 보행을 멈추고, 빈 바닥·막힌 연결부·대각선 틈으로 통과할 수 없다.
- **석판 방 완료:** 조립은 보행 길만 활성화하며 순간이동하지 않는다. WASD로 반대 끝까지 걸어야 통과 기록이 남고 외부 반대편에 도착한다. 완료 후 같은 회차에 양방향 재이용할 수 있다. Esc·입구 후퇴·시간대 중단은 저장한 외부 위치·방향으로 복귀한다. 같은 시간대에는 배치를 유지하고, 아직 직접 통과하지 않은 방은 전환 때 초기화하며 통과 완료한 방은 유지한다.
- **경로 선택:** 미로를 직접 그리는 방식이 아니다. 생성된 두 후보 카드의 실제 거리(칸)와 기준 노출 수를 비교하고 확정 버튼을 누른다. 클릭만으로 예약하지 않으며 확정 후 회차 안에서 변경할 수 없다. `U` 출발→`V` 합류의 현재 거리와 각 후보 거리를 표시하고, 노출은 현재 수호자 위치·예정 지형 기준으로 계산한다. 노출 0도 이후 안전을 보장하지 않는다.

### 5.3 세계 진행·피격·전환

- 마우스 미로·경로 선택 패널을 연 동안 세계 시간과 수호자 추적·공격이 진행된다. 피격되면 패널을 닫고 입력을 해제한다. 마우스 미로는 같은 시간대에 마지막 커서부터 재개할 수 있다.
- 마우스 버튼 해제·포커스 상실은 드래그 입력을 해제한다. 시간대 전환 때 미완료 마우스 경로와 미확정 선택은 초기화한다.
- 경로 확정은 시간대 경계·피격 처리 후 확인한다. 실패나 전환이 발생한 프레임에서 잘못 예약하지 않도록 한다.
- 석판 방은 시간대 타이머는 계속 흐르지만 외부 수호자는 갱신하지 않는다. 완료한 방 통과 기록과 다음 시간대 예약 기록은 서로 별도다.

## 6. 경로와 회차별 배치

| 경로 | 이용 방식·결과 |
| --- | --- |
| 일반 통로 | 이동·전투·회피로 중앙 접근. 퍼즐·함정방을 이용하지 않아도 탈출 가능 |
| 마우스 미로·경로 선택 | 다음 시간대의 국소 숏컷을 예약 |
| 두 문양 석판 방 | 조립 후 직접 걸어 반대편으로 통과 |
| 함정형 숏컷 | 살아서 완주하면 A→B/C→D 연결 출구로 이동해 길 단축. 중도 취소·전환은 입구 복귀 |

- 경로 선택은 특정 시드 117·회차 0만의 고정 배치를 벗어나 현재 시드·회차 지형에서 두 유효 후보를 탐색한다. 세 시간대와 마우스 퍼즐 문 개방 여부를 함께 검사한다.
- 같은 출발·합류점, 실제 통행, 선택한 문만 개방, 일반 탈출 경로 유지, 국소 거리 이득과 중앙까지 8칸 이상 남는 조건 등을 만족해야 한다. 두 후보를 확보하지 못하면 경로 선택을 생략한다. 모든 시드·회차에 생성하거나 항상 안전하다는 보장은 없다.
- 후보 이름은 현재 코드의 `1번 통로`·`2번 통로`를 사용한다. 거리·노출 수는 배치와 수호자 위치에 따라 달라지므로 고정 수치나 '안전 길'로 규정하지 않는다.
- 함정방은 입구 A/C와 연결 출구 B/D의 쌍으로 배치한다. 주요 지점과의 간격, 국소 거리 이득, 중앙까지 남은 탐색, 시간대별 입출구·중도 복귀 안전성을 검사한다. 유효한 돌방 입출구 쌍이 없으면 생략하며 모든 회차 배치를 보장하지 않는다.
- 석판 방 거리 검사는 방 내부 보행을 16칸으로 환산하고 퍼즐 조작 시간을 제외한다. 입구까지 우회한 총거리와 입구 도착 후 국소 거리 이득은 다를 수 있으며 이를 실제 시간 단축으로 표현하지 않는다.
- 시간대별 유형 수와 위치를 전면 무작위화하는 확장은 후속 결정이다. 과거 시간대별 3곳·총 9곳 기본안은 현재 구현 수나 확정 보장으로 쓰지 않는다.
- 새 회차는 스폰·배치를 다시 정하고 선택·예약·개방·석판 방 통과·함정방 발견·통과 기록을 초기화한다.

### 7.1 입장·통과·중도 복귀

- 진입할 때 입장 직전 외부 실수 좌표, 격자 방향과 화면 방향을 저장한다. 내부 진행·속도를 초기화하고 교차 돌방의 시선도 시작 방향으로 돌린다.
- 칼날방 정상 완주는 A→B, 교차 돌방 정상 완주는 C→D의 연결 출구 통로로 이동한다. 일반 통로의 일부 우회를 줄이고 중앙까지 탐색 구간을 남긴다.
- 교차 돌방은 여섯 줄 뒤 정면 출구 근처에서 F를 누르거나 끝까지 걸어 완주한다. 독립 연습의 측면 출구와 구분한다.
- Esc 중도 취소·시간대 전환만 저장한 정확한 입장 좌표·방향으로 복귀한다. 단순 입장이나 중단을 B/D 도착·통과로 기록하지 않는다. 사망은 실패이며 연결 출구로 보내지 않는다.
- 함정방은 보상 지급·방별 보상 획득 기록을 사용하지 않는다. 통과 여부와 지도상의 도착점 발견은 이동 결과를 위한 기록이다.
- 교차 돌방은 시간대 전환→Esc 복귀→돌 접촉 실패→정면 출구 완료 순으로 처리한다. 실패 화면에서 R로 새 회차를 시작한다.
- 입출구와 복귀 지점 주변 통로를 시간대별로 보존하고, 외부로 나온 뒤 일반 미로의 수호자 규칙을 적용한다.

### 7.2 조작·표시

칼날방·본게임 돌방·[`독립 돌 연습`](../BoulderPractice/boulder_practice.py)은 마우스 수평 360° 회전과 시선 기준 WASD를 공유한다. Q 후방 보기는 없다. 본게임 HUD는 자원·시간대·남은 시간·진행 정보를 표시하고 전환 시 입장 위치로 복귀함을 안내한다. 독립 연습의 무적 규칙을 본게임 즉사 규칙과 혼동하지 않는다.

## 8. 체력·스태미너·회복

- 체력과 스태미너의 최대값은 각각 100이다. 체력은 피해로 감소하고, 0이면 실패한다. 체력 자연 회복과 시간대 전환 자동 회복은 없다.
- 스태미너는 새벽에만 세계 시간 기준 초당 8씩 회복한다. 일반 미로와 칼날방·본게임 돌방에서 달리기로 실제 이동하면 초당 18씩 차감한다. 돌방의 본게임 자원 소모·새벽 회복은 중복 적용하지 않는다. 스태미너가 부족하면 걷기와 퍼즐 조작을 계속할 수 있다.
- 샘물은 회차당 1곳이다. F를 누르면 체력 35를 최대값까지 회복한다. 사용 상태는 세 시간대가 공유하고, 물이 남았는지 고갈됐는지 그림을 바꿔 표시한다.
- 현재 단검 공격의 스태미너 소모는 0이다. 회피·공격 비용, 샘물 추가 배치와 회복량 조정은 후속 검토 항목이다.

## 9. 방문 지도·단서·HUD

- M키로 현재 시간대의 방문 지도를 연다. 직접 밟은 칸과 자신의 위치를 표시하고, M 또는 Esc로 닫는다. 시간대가 바뀌면 해당 시간대의 방문 기록을 사용한다.
- 방문 지도에는 발견한 칼날방 A·돌방 C와 정상 통과한 연결 출구 B/D, 석판 방 L을 구분해 표시한다. 석판 방의 반대편 L은 직접 통과 후 표시한다. 일반 탐색 화면의 퍼즐 표식·경로 선택 U/V와 방문 지도 표시는 구분한다.
- 지도를 보는 동안 이동·공격·상호작용 입력을 막고 세계 시간과 수호자 추적·공격은 계속 진행한다. 공격 예고 시 지도에 경고 문구를 표시하며 피격 때 지도가 닫힌다.
- 중앙 탈출구는 미로에서 로프로 표시한다. 중앙 방향 소리, 바닥·벽 문양과 청각 대체 표시는 후속 검토 항목이다.
- HUD에 체력·스태미너·횃불 획득 여부·시간대·남은 시간·변형 예고를 표시한다. 퍼즐은 풀이 가능, 예약, 개방을 표시하며 미리보기는 퍼즐 패널 오른쪽에 둔다. 성공·실패 화면에서 R로 새 회차를 시작한다.

## 13. 완료·플레이테스트 기준

구현 확인에 사용하는 검사와 범위는 11.3절을 따른다. 다음은 후속 기능도 포함한 플레이테스트 기준이다.

1. 낮→밤→새벽→낮 반복과 새벽 종료만으로 실패하지 않는 규칙이 동작한다.
2. 13×9 마우스 미로 양쪽 접근, 경유 1→2→3 순서, 벽 가로지르기 차단·되짚기·입력 재개를 확인한다. 경유 후 도착해야 예약하고 다음 시간대에 문이 열린다.
3. 피격 후 같은 시간대에 이어 풀고, 전환 시 미완료 진행은 초기화한다.
4. 개방·석판 방 통과·함정방 발견/통과 기록은 판 내 유지하며 새 판은 자원·선택·예약·진행·개방·방문·통과 기록을 초기화한다.
5. 체력 자연 회복 없음·샘물 1회 사용·스태미너 새벽 회복·자원 0에서도 기본 진행이 동작한다.
6. 중앙 로프에서 F를 눌러 CLEAR에 도달하고, 체력 0으로 실패한 뒤 R로 재시작한다. 본게임 교차 돌 접촉 즉사와 실패 시 출구 이동이 없음을 확인한다. 로프 상승·암전은 후속 범위다.
7. 쿼터뷰 화면·충돌·방문 지도가 같은 격자 위치를 사용한다. 플레이어의 방향과 관계없이 주변 원형 시야를 유지하고, 횃불을 얻으면 반경이 늘어난다. 벽 뒤 사물은 시야에 들어오기 전까지 가린다. 함정방에서도 자원·시간을 공유하고 통과/복귀 위치가 일치한다.
8. 지도 중 세계 진행·접근 경고·피격 시 닫기가 동작하고 미방문 지형을 공개하지 않는다.
9. 생성된 경로 후보는 일반 탈출 경로·국소 거리 이득·남은 탐색·원본 보존 조건을 충족한다. 후보가 없는 회차도 생략 후 정상 진행한다. 거리·노출 표시는 고정 수치나 안전 보장이 아니다.
10. 시간대 전환 시 충돌을 한 번 교체하고, 함정방은 원래 위치로 복귀하며 주변 통로를 보존한다.
11. 화면 안내와 실제 조작이 일치하고 실제 실행 창에서 통합 성능을 확인한다.
12. 타인이 목표·지연 적용·경로 선택 이유를 이해하는지 확인하고, 실제 한 판 시간·반복 횟수·사망 원인·퍼즐 및 통과 시간을 기록해 조정한다.
13. 8방향 대기·걷기·단검 공격과 대각선 4방향 달리기의 방향·발 기준점이 맞는다. 공격 모션, 칼끝 효과, 실제 233ms·466ms 타격을 확인한다. 피격 모션 연결 후 그림 오프셋과 충돌 위치도 검사한다.

14. 칼날방·본게임 돌방·독립 연습에서 정지 상태 시선 회전, 회전 직후 WASD 방향, 대각 이동·충돌·Q 무효·포커스·IME를 확인한다.
15. 두 문양 연결만으로 이동 완료되지 않고 실제 보행으로만 반대편에 도착한다. 역방향 재이용·빈 칸/막힌 면·Esc/후퇴/전환 복귀를 확인한다.
16. 함정 정상 완주만 A→B/C→D 연결 출구로 이동한다. 취소·전환은 정확한 입구 좌표·방향 복귀, 사망은 실패다. 입출구 쌍의 길 단축·남은 탐색·안전성을 확인하고 보상 지급·획득 기록은 사용하지 않는다.
