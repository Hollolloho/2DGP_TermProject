## 현재 실행 범위

구형 에셋과 참조를 정리했다. 이동·벽 충돌·시야·샘물·방문 지도·수호자 전투·마우스 미로 퍼즐·1인칭 칼날방을 검사할 수 있다.

일반 미로는 기존 2D 격자 위에 쿼터뷰 바닥·벽·소품·함정방 입출구·수호자를 그린다. 플레이어는 이동 방향에 맞춰 대기·걷기·달리기·공격 시트를 재생한다. 발 위치와 벽의 지면 기준점으로 가림 순서를 계산한다. 함정방에 들어가면 정면 고정 1인칭으로 전환된다.

일반 미로의 시야는 캐릭터가 보는 방향과 관계없이 플레이어 중심 원형이다. 격자 기준 기본 반경은 5.5칸이고, 횃불을 얻으면 7칸으로 늘어난다. 벽 뒤와 반경 밖은 현재 시야에서 제외된다. 전에 확인한 지형은 어둡게 남는다.

## 실행

저장소 루트에서 실행한다. Python과 `requirements.txt`의 pico2d·transitions가 필요하다. Windows 맑은 고딕을 사용한다.

```powershell
python -m pip install -r requirements.txt
python -m SourceCode.main
python -m BoulderPractice.boulder_practice
```

일반 미로 창은 1280×800, 내부 화면은 640×400이다. `--overview`는 전체 미로 검사, `--trap-preview`는 칼날방 이동 검사에 사용한다.

| 입력 | 현재 동작 |
| --- | --- |
| W / A / S / D | 일반 미로에서 통로 방향 이동. 화면에서는 각각 북서 / 남서 / 남동 / 북동 |
| Shift + 이동 | 달리기·스태미너 소모 |
| 마우스 좌클릭 | 화면 8방향 단검 2연타 |
| F | 횃불·샘물·함정방·마우스 미로·중앙 탈출구 상호작용 |
| M | 방문 지도. 세계 시간은 계속 진행 |
| V | 전체 미로 검사 보기 전환 |
| R | 새 회차·스폰 변경·시작 시간대 낮→밤→새벽 순환 |
| F10 | `output/topdown/manual.png` 저장 |
| Esc | 지도·퍼즐 닫기 / 함정방 원위치 복귀 / 탐색 중 종료 |
| 함정방 W/S, A/D | 전진·후진, 좌우 회피 |

일반 미로에서 서로 다른 축의 두 키를 함께 누르면 격자 기준 대각선으로 이동한다. 반대 방향 키는 서로 상쇄된다. 단일 키로 걷거나 달릴 때는 통로 방향의 기존 모션을 사용한다.

좌클릭 한 번으로 시작 방향을 향해 베고 되벤다. 750ms 동작의 233ms와 466ms에 각각 앞쪽 1.8칸 이내 수호자를 확인해 피해를 준다. 벽이 사이에 있으면 해당 타격이 막히며, 다음 공격은 동작이 끝난 뒤 시작할 수 있다.

수호자는 벽에 가리지 않은 6칸 이내에서 플레이어를 발견해 통로로 추적한다. 가까이 오면 머리 위에 `!`를 띄워 공격을 예고한다. 예고가 끝날 때 1.25칸 이내이고 벽이 사이에 없으면 피해 15를 준다.

수호자는 마우스 미로 퍼즐을 풀거나 방문 지도를 보는 중에도 움직이고 공격한다. 피격되면 열려 있던 화면이 닫힌다. 퍼즐에서 그린 경로는 남으므로 같은 시간대에 퍼즐 앞에서 F를 누르면 이어서 풀 수 있다. 시간대가 바뀌면 미완료 경로가 초기화되고, 완료한 퍼즐이 예약한 통로가 열린다.

일반 미로와 칼날방 모두 HP가 0이면 실패하며 R로 새 회차를 시작한다. 방문 지도는 지나간 통로를 표시하고, 함정방 도착점은 통과 후 표시한다. Space 회피·추가 퍼즐·로프 상승 엔딩·돌 함정의 본 게임 연결은 후속 구현이다. 독립 돌 연습은 무적 모드다.

## 에셋 연결

- 플레이어는 `sprite/quarter/player_explorer_attack_v2/`의 `explorer.png`와 `explorer.json`을 사용한다. 각 타격의 검격 효과는 재생 중인 프레임의 단검 칼끝을 따라간다.
- 지형·소품·수호자·함정형 숏컷은 각 `catalog.json`의 프레임과 지면 기준점을 사용한다.
- 돌방 사물: `sprite/traps/boulder_room_v2/catalog.json`의 `props`·`exits`를 읽는다.
- `sprite/traps/boulder_chase_v1/catalog.json`은 **먼지 전용**이다.
- 1인칭 벽·바닥·천장 원본 재질, 회전 돌 재질, 칼날, 불꽃·검격 효과, 효과음은 재사용한다.
- 삭제된 시트의 재패킹 도구와 구형 돌 비교용 복사 코드는 제거했다. 에셋 제작용 도구는 각 새 에셋 폴더에서 관리한다.

## 검사

다음 명령은 저장소 루트에서 실행한다. 화면 검사는 SDL dummy renderer를 사용한다.

```powershell
python -m TestCode.checks_assets
python -m TestCode.checks_topdown
python -m TestCode.check_boulder_practice
python -m SourceCode.main --smoke
python -m BoulderPractice.boulder_practice --smoke --width 1280 --height 800
python -m TestCode.check_visuals
```

[`TestCode/checks_assets.py`](TestCode/checks_assets.py)는 재사용 파일·프레임 좌표·발 기준점·출구 개구부와 준비/미완료 묶음을 확인한다. `--require-complete`를 붙이면 제작 중인 에셋이 하나라도 있을 때 실패한다.

수호자 피격으로 퍼즐이 닫히는 상황은 `python -m SourceCode.main --seed 120`으로 확인할 수 있다. 시작점에서 모퉁이 중앙을 따라 W 14칸 → A 2칸 → W 4칸 → D 2칸 → W 4칸을 걷는다. 퍼즐 앞에서 첫 피격으로 HP가 85가 되면 F를 누르고, 시작점에서 오른쪽으로 한 칸 드래그한 채 기다린다. 두 번째 피격으로 HP가 70이 되면 퍼즐이 닫힌다. 마우스 버튼을 놓고 F를 눌러 마지막 지점부터 이어서 드래그한다.

규칙 검사는 32개 미로의 연결성·충돌·복귀, 원형 시야와 횃불 반경 확대, 돌 연습의 이동·접촉·스태미너·출구를 확인한다. 화면 검사는 SDL 키 입력으로 일반 미로의 통로 방향·두 키 대각선 이동, 대응 모션과 함정방 전환·복귀를 확인한다. 캡처와 검사 결과는 Git에서 제외하는 `output/topdown/`에 저장한다.
