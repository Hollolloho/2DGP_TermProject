## 현재 실행 범위

일반 미로 탐색, 시간대별 지형 변형, 수호자 전투, 마우스 미로 퍼즐, 1인칭 칼날방과 중앙 탈출을 플레이할 수 있다. 돌 추격은 별도 무적 연습으로 실행한다.

일반 미로는 기존 2D 격자 위에 쿼터뷰 바닥·벽·소품·함정방 입출구·수호자를 그린다. 플레이어는 이동 방향에 맞춰 대기·걷기·달리기·공격 시트를 재생한다. 발 위치와 벽의 지면 기준점으로 가림 순서를 계산한다. 함정방에 들어가면 정면 고정 1인칭으로 전환된다.

일반 미로는 캐릭터의 방향과 관계없이 플레이어 주변을 원형으로 밝힌다. 격자 기준 반경은 기본 5.5칸이며, 횃불을 얻으면 7칸으로 늘어난다. 벽은 뒤쪽 시야를 가리고, 새로 보이는 지형은 약 0.2초에 걸쳐 밝아진다. 현재 시간대에서 전에 확인한 지형은 어둡게 남는다.

## 실행

저장소 루트에서 실행한다. Python과 `requirements.txt`의 pico2d·transitions가 필요하다. Windows 맑은 고딕을 사용한다.

```powershell
python -m pip install -r requirements.txt
python -m SourceCode.main
python -m BoulderPractice.boulder_practice
```

일반 미로 창은 1280×800, 내부 화면은 640×400이다. 기본 시드는 117이다. `--seed`로 배치를 바꾸고, `--overview`로 전체 미로를 보거나 `--trap-preview`로 칼날방에서 바로 시작할 수 있다.

| 입력 | 현재 동작 |
| --- | --- |
| W / A / S / D | 일반 미로에서 통로 방향 이동. 화면에서는 각각 북서 / 남서 / 남동 / 북동 |
| Shift + 이동 | 달리기·스태미너 소모 |
| 마우스 좌클릭 | 일반 미로에서 화면 8방향 단검 2연타 |
| 좌클릭을 누른 채 드래그 | 마우스 미로에서 통로를 따라 출발과 도착 연결 |
| F | 횃불·샘물·함정방·마우스 미로·중앙 탈출구 상호작용 |
| M | 현재 시간대 방문 지도. 플레이어 이동은 멈추고 세계 시간은 계속 진행 |
| V | 전체 미로 검사 보기 전환 |
| R | 새 회차·스폰 변경·시작 시간대 낮→밤→새벽 순환 |
| F10 | `output/topdown/manual.png` 저장 |
| Esc | 지도·퍼즐 닫기 / 함정방 원위치 복귀 / 탐색 중 종료 |
| 함정방 W/S, A/D | 전진·후진, 좌우 회피 |

일반 미로에서 서로 다른 축의 두 키를 함께 누르면 격자 기준 대각선으로 이동한다. 반대 방향 키는 서로 상쇄된다. 걷기와 달리기는 화면에 투영된 지면 거리에 맞춰 속도와 보행 프레임을 계산한다.

좌클릭 한 번으로 시작 방향을 향해 베고 되벤다. 750ms 동작의 233ms와 466ms에 각각 앞쪽 1.8칸 이내 수호자를 확인해 피해를 준다. 벽이 사이에 있으면 해당 타격이 막히며, 다음 공격은 동작이 끝난 뒤 시작할 수 있다.

수호자는 벽에 가리지 않은 6칸 이내에서 플레이어를 발견해 통로로 추적한다. 가까이 오면 머리 위에 `!`를 띄워 공격을 예고한다. 예고가 끝날 때 1.25칸 이내이고 벽이 사이에 없으면 피해 15를 준다.

### 시간대와 마우스 미로

낮 → 밤 → 새벽 순으로 각 시간대가 60초 동안 이어진다. 5초 전에 전환을 예고하고, 지형을 바꾸는 동안 플레이를 잠시 멈춘다.

낮·밤·새벽 모두, 문이 시야에 들어오면 양쪽 접근 칸에서 F로 퍼즐을 열 수 있다. 마우스로 통로를 따라 그리면 지나온 칸에 금빛이 남고 현재 네모 커서 쪽이 더 밝다. 되짚으면 경로에서 빠지는 칸의 색이 사라진다. 벽에 닿으면 마지막 유효 위치에서 멈추며, 버튼을 놓았다가 그 위치에서 다시 이어 그릴 수 있다.

풀이 중에는 퍼즐 창에서 현재와 다음 시간대의 문 주변을 비교할 수 있다. 도착 칸에 들어가는 즉시 개방이 예약되고 퍼즐 창이 닫힌다. 예약된 문은 다음 전환에 열리고 새 회차를 시작할 때 초기화된다.

퍼즐과 방문 지도를 열어도 수호자는 움직이고 공격한다. 피격되면 열린 화면이 닫힌다. 같은 시간대에는 F로 마지막 경로부터 이어 풀 수 있고, 시간대가 바뀌면 미완료 경로가 초기화된다.

칼날방을 통과하면 숏컷 도착점 B로 이동한다. Esc를 누르거나 시간대가 바뀌면 입장 전 위치로 돌아간다. 일반 미로와 칼날방 모두 HP가 0이면 실패하며 R로 새 회차를 시작한다. Space 회피, 추가 퍼즐, 로프 상승 엔딩, 돌 함정의 본 게임 연결은 후속 구현이다.

## 에셋 연결

- 플레이어는 `sprite/quarter/player_explorer_attack_v2/`의 `explorer.png`와 `explorer.json`을 사용한다. 이동 중 공격은 `moving-attack.png`의 상체와 다리 프레임을 합성한다. 검격 효과는 재생 중인 프레임의 단검 칼끝에 맞춰 그린다.
- 지형·소품·수호자·함정형 숏컷은 각 `catalog.json`의 프레임과 지면 기준점을 사용한다.
- 마우스 미로 패널은 `sprite/ui/mouse-maze-panel.png`를 사용한다. 통로와 벽은 기존 석재 재질로 그린다.
- 독립 돌 연습은 `sprite/traps/boulder_room_v2/catalog.json`의 `props`와 `exits`를 읽는다.
- `sprite/traps/boulder_chase_v1/catalog.json`은 **먼지 전용**이다.
- 1인칭 벽·바닥·천장 원본 재질, 회전 돌 재질, 칼날, 불꽃·검격 효과, 효과음은 재사용한다.

## 검사

다음 명령은 저장소 루트에서 실행한다. 스모크 검사는 SDL의 더미 비디오·오디오 드라이버로 창 없이 실행한다.

```powershell
python -m TestCode.checks_assets
python -m TestCode.checks_topdown
python -m TestCode.checks_phase_changes
python -m TestCode.checks_gait
python -m TestCode.check_boulder_practice
python -m SourceCode.main --smoke
python -m BoulderPractice.boulder_practice --smoke --width 1280 --height 800
python -m TestCode.check_visuals
```

[`TestCode/checks_assets.py`](TestCode/checks_assets.py)는 재사용 파일·프레임 좌표·발 기준점·출구 개구부와 준비/미완료 묶음을 확인한다. `--require-complete`를 붙이면 제작 중인 에셋이 하나라도 있을 때 실패한다.

수호자 피격으로 퍼즐이 닫히는 상황은 `python -m SourceCode.main --seed 120`으로 확인할 수 있다. 시작점에서 Shift를 누르지 않고 모퉁이 중앙을 따라 W 14칸 → A 2칸 → W 4칸 → D 2칸 → W 4칸을 걷는다. 퍼즐 앞에서 첫 피격으로 HP가 85가 되면 F를 누르고, 시작점에서 오른쪽으로 한 칸 드래그한 채 기다린다. 두 번째 피격으로 HP가 70이 되면 퍼즐이 닫힌다. 마우스 버튼을 놓고 F를 눌러 마지막 지점부터 이어서 드래그한다.

규칙 검사는 미로의 연결성과 충돌, 시간대 변형, 퍼즐 재개·예약 개방, 시야, 보행과 돌 연습 규칙을 확인한다. SDL 스모크는 키·마우스 이벤트와 화면 픽셀로 이동, 단검 타격, 퍼즐의 금빛 경로, 함정방 전환·복귀를 검사한다. 스모크와 돌 연습 검사에서 생성되는 캡처와 결과는 기본적으로 Git에서 제외되는 `output/topdown/` 또는 `output/boulder_practice/`에 저장된다.
