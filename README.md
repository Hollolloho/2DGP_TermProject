# 초보자를 위한 미로 탈출 안내서

최신 기획은 `PRD.md`, 교체 에셋 규격·제작 목록은 `ASSET_TASKS.md`를 따른다.

## 현재 실행 범위

구형 에셋과 참조를 정리했다. 이동·벽 충돌·시야·샘물·방문 지도·정지 수호자 타격·1인칭 칼날방을 검사할 수 있다.

일반 미로는 기존 2D 격자 위에 쿼터뷰 바닥·벽·소품·함정방 입출구·수호자를 그린다. 플레이어는 이동 방향에 맞춰 대기·걷기·달리기·공격 시트를 재생한다. 발 위치와 벽의 지면 기준점으로 가림 순서를 계산한다. 함정방에 들어가면 정면 고정 1인칭으로 전환된다.

일반 미로의 시야는 캐릭터가 보는 방향과 관계없이 플레이어 중심 원형이다. 격자 기준 기본 반경은 5.5칸이고, 횃불을 얻으면 7칸으로 늘어난다. 벽 뒤와 반경 밖은 현재 시야에서 제외된다. 전에 확인한 지형은 어둡게 남는다.

## 실행

Python과 `requirements.txt`의 pico2d·transitions가 필요하다. Windows 맑은 고딕을 사용한다.

```powershell
python -m pip install -r requirements.txt
python main.py
python boulder_practice.py
```

일반 미로 창은 1280×800, 내부 화면은 640×400이다. `--overview`는 전체 미로 검사, `--trap-preview`는 칼날방 이동 검사에 사용한다.

| 입력 | 현재 동작 |
| --- | --- |
| W / A / S / D | 일반 미로에서 화면 기준 위 / 왼쪽 / 아래 / 오른쪽 이동 |
| W+A / W+D / S+A / S+D | 일반 미로에서 각각 화면 북서 / 북동 / 남서 / 남동 이동 |
| Shift + 이동 | 달리기·스태미너 소모 |
| 마우스 좌클릭 | 화면 8방향 단검 2연타 |
| F | 횃불·샘물·함정방·중앙 탈출구 상호작용 |
| M | 방문 지도. 세계 시간은 계속 진행 |
| V | 전체 미로 검사 보기 전환 |
| R | 새 회차·스폰 변경·시작 시간대 낮→밤→새벽 순환 |
| F10 | `output/topdown/manual.png` 저장 |
| Esc | 지도 닫기 / 함정방 원위치 복귀 / 탐색 중 종료 |
| 함정방 W/S, A/D | 전진·후진, 좌우 회피 |

반대 방향 키는 서로 상쇄된다. 대각선 이동에도 격자 기준 이동 속도를 유지한다. 걷기와 달리기는 기존 대각선 4방향 모션을 사용한다. 화면 상하좌우로 움직일 때는 가까운 대각선 모션을 일관되게 선택한다.

좌클릭 한 번으로 시작 방향을 향해 베고 되벤다. 750ms 동작의 233ms와 466ms에 각각 앞쪽 1.8칸 이내 수호자를 확인해 피해를 준다. 벽이 사이에 있으면 해당 타격이 막히며, 다음 공격은 동작이 끝난 뒤 시작할 수 있다.

칼날방에서 HP가 0이 되면 실패하며 R로 새 회차를 시작한다. 방문 지도는 지나간 통로를 표시하고, 함정방 도착점은 통과 후 표시한다. 60초 조명 전환은 시제품 규칙이다. Space 회피·몬스터 AI·시간대별 지형 변형·실제 퍼즐과 예약 개방·로프 상승 엔딩·돌 함정의 본 게임 연결은 후속 구현이다. 독립 돌 연습은 무적 모드다.

## 에셋 연결

- 플레이어는 `sprite/quarter/player_explorer_attack_v2/`의 `explorer.png`와 `explorer.json`을 사용한다. 각 타격의 검격 효과는 재생 중인 프레임의 단검 칼끝을 따라간다.
- 지형·소품·수호자·함정형 숏컷은 각 `catalog.json`의 프레임과 지면 기준점을 사용한다.
- 돌방 사물: `sprite/traps/boulder_room_v2/catalog.json`의 `props`·`exits`를 읽는다.
- `sprite/traps/boulder_chase_v1/catalog.json`은 **먼지 전용**이다.
- 1인칭 벽·바닥·천장 원본 재질, 회전 돌 재질, 칼날, 불꽃·검격 효과, 효과음은 재사용한다.
- 삭제된 시트의 재패킹 도구와 구형 돌 비교용 복사 코드는 제거했다. 에셋 제작용 도구는 각 새 에셋 폴더에서 관리한다.

## 검사

다음 명령은 창을 조작하지 않고 실행된다. 화면 검사는 SDL dummy renderer를 사용한다.

```powershell
python checks_assets.py
python checks_topdown.py
python check_boulder_practice.py
python main.py --smoke
python boulder_practice.py --smoke --width 1280 --height 800
python sprite/traps/boulder_volume_v2/tools/check_visuals.py
```

`checks_assets.py`는 재사용 파일·프레임 좌표·발 기준점·출구 개구부와 준비/미완료 묶음을 확인한다. `--require-complete`를 붙이면 제작 중인 에셋이 하나라도 있을 때 실패한다.

규칙 검사는 32개 미로의 연결성·충돌·복귀, 원형 시야와 횃불 반경 확대, 돌 연습의 이동·접촉·스태미너·출구를 확인한다. 화면 검사는 SDL 키 입력으로 일반 미로의 상하좌우·대각선 이동, 대응 모션과 함정방 전환·복귀를 확인한다. 캡처와 검사 결과는 Git에서 제외하는 `output/topdown/`에 저장한다.
