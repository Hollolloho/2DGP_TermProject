# 초보자를 위한 미로 탈출 안내서 — 하이브리드 시점 시제품

일반 미궁은 픽셀 탑뷰, 함정방은 정면 고정 1인칭으로 표현한다. Python 3.13, pico2d, transitions를 사용한다.

## 실행

```powershell
python main.py
```

전체 타일을 먼저 확인하려면 `python main.py --overview`로 실행한다. 이 옵션은 시제품의 디자인 확인용이며 V로 정상 시야로 돌아간다. 기본 실행은 방향성 시야이며 횃불을 얻으면 원형 시야가 넓어진다. 창은 1280×800, 탑뷰 내부 해상도는 640×400을 정수 2배 확대한다. 함정방은 기존 고해상도 원근 부품을 창 해상도에 직접 그린다.

현재 환경에 pico2d와 transitions가 설치되어 있다. 다른 환경에서 설치하려면 `python -m pip install -r requirements.txt`를 사용한다. 한국어 글꼴은 Windows의 맑은 고딕을 사용한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 탑뷰 이동 |
| Shift + 이동 | 달리기·스태미너 소모 |
| 마우스 좌클릭 | 짧은 검 공격 효과·가까운 수호자 타격 |
| F | 횃불·샘물·함정방 입구·중앙 탈출구 상호작용 |
| M | 방문 지도. 지도를 열어도 세계 시간은 진행 |
| V | 정상 시야 / 전체 미로 보기. 전체 보기는 디자인 확인용 |
| R | 새 회차. 스폰 변경, 시작 시간대 낮→밤→새벽 순환 |
| F10 | 현재 화면을 `output/topdown/manual.png`에 저장 |
| Esc | 지도 닫기 / 함정방에서 입장 전 위치로 복귀 / 탐색 중 창 닫기 |
| 함정방 W / S | 전진·후진 |
| 함정방 A / D | 좌우 이동으로 칼날 회피 |

초기 위치 근처에 횃불과 함정방을 배치한다. 횃불에서 F를 누른 뒤 가까운 검은 돌문 입구로 가서 F를 누르면 1인칭 칼날 방으로 전환한다. 통과하면 일반 미로의 조금 앞쪽 통로로 나오며, Esc나 시간대 전환으로 나가면 입장 전 좌표로 돌아간다.

## 파일

- `main.py`: 입력 처리 → 갱신(dt) → 그리기의 기본 게임 루프와 창 실행.
- `maze_model.py`: 격자 미로·이동·충돌·시야·자원·상호작용. 게임 FSM과 플레이어 FSM을 각각 transitions로 관리.
- `game_view.py`: 같은 모델을 탑뷰 또는 1인칭으로 그리는 별도 표현 계층.
- `sprite/topdown`: 벽 16연결형·바닥 8변형·소품 8종, 플레이어·수호자 4방향 각 3프레임, pixelfx 효과.
- `sprite/wall`, `sprite/surfaces`: 앞서 제작한 원근 부품. 함정방에서 재사용.
- `output/topdown`: 실제 pico2d 화면 캡처와 실행 중 상태 기록. 생성되며 Git 커밋은 자동으로 하지 않는다.

픽셀 시트는 기존 벽·바닥 원본 재질을 샘플링하고 색 수를 줄인 타일에 pixelfx Painter로 경계와 소품·캐릭터를 그려 제작했다. `fire/torch`, `melee/sword-slash` 효과는 pixelfx에서 내보낸 시트다. MIT 라이선스·고지를 `sprite/topdown`에 포함했으며 제외 라이선스인 gallery 글꼴은 사용하지 않았다.

## 현재 범위

동작하는 시제품: 미로 이동·벽 충돌, 랜덤 스폰, 방향성/횃불 시야, 방문 지도, 기본 검격·정지한 수호자 타격, 샘물, 게임/플레이어 FSM, 함정방 시점 전환·칼날 충돌·통과/복귀.

후속 구현: 세 시간대별 지형과 변형, 실제 퍼즐 3종 및 예약 개방, 숏컷 무작위 배치 규칙, 몬스터 추적·공격 AI, 돌 추격 함정, 확정된 사망/재시작 처리와 로프 상승 엔딩. 현재 60초마다 시간대 조명만 바뀌며 미로 지형은 동일하다. 수호자는 타격 확인용으로 정지해 있다. 칼날에 체력 0이 되면 시제품에서는 체력을 초기화하고 입구로 복귀한다. 이는 최종 사망 규칙 구현을 의미하지 않는다.

현재 미로는 31×23의 시험용 격자이며 고정 seed에서 만들고 순환 통로를 추가했다. 확정된 낮·밤·새벽 맵이나 최종 난이도가 아니다. 기존에 생성한 에셋과 발표 자료는 보존했다.

## 이동감·숏컷 피드백 수정 (2026-11-05)

- 기존 함정방은 벽·바닥이 고정되고 칼날만 접근했다. 현재는 고정 통로의 벽·바닥·천장 텍스처와 기둥을 같은 공간 좌표로 원근 변환한다. 전후·좌우 이동에 따라 UV와 원근이 함께 바뀐다. 임의 미로를 탐색하는 레이캐스팅은 사용하지 않는다.
- 함정방은 전체 창을 사용하고 최소 HUD만 겹친다. 이동 가속·정지, 걸음에 맞춘 작은 시점 흔들림, 발소리와 칼날 통과 소리, 피격 반응을 추가했다. WAV 두 개는 직접 합성한 원본이다.
- 선으로 그렸던 칼날은 투명 철제 칼날 에셋으로 교체했다. 화면 위치와 충돌 모두 동일한 칼날 위치·실제 깊이·반지름에서 계산한다.
- A는 함정방 입구, B는 도착점이다. 함정방 자체가 A/B를 잇는 별도 통로이며, 외부 미로의 벽을 갑자기 뚫는 기능이 아니다. 지도에는 연결을 점선으로 표시하되 그 사이의 미방문 지형은 공개하지 않는다.
- 기본 seed의 연결은 일반 통로 17칸을 우회하며, 중앙까지 남은 일반 탐색을 보존한다. 끝나면 B에 도착했다는 메시지와 바닥 표시를 준다. 실제 최종 맵의 무작위 숏컷 이득은 후속 검증 대상이다.
- 정상 탑뷰는 플레이어를 따라가며 확대하고, V 전체 보기는 기존처럼 미로 전체를 표시한다. 미술 스타일은 사용자 참고 이미지가 오기 전까지 확정하지 않았다.
- 플레이어와 비슷했던 타격 확인용 수호자는 별도의 큰 방패 스프라이트·이름·체력 표시로 구분했다. 추적 AI는 아직 추가하지 않았다.
- `python main.py --trap-preview`로 바로 함정방 이동을 확인할 수 있다. 이 검토용 실행 옵션은 시작 위치와 횃불을 준비하며, 일반 새 게임에는 적용하지 않는다.
- `output/fixes/trap-motion.gif`는 실제 SDL 렌더러에서 모델의 이동 입력으로 만든 움직임 기록이다. 입력을 정지한 뒤 칼날만 바꾼 영상이 아니다. `shortcut-map.png`와 `shortcut-arrival.png`에서 연결·도착 표시를 확인할 수 있다.

검사 범위: 32 seed의 연결성·충돌, 이동 중 시간대 전환 원위치 복귀, 기본 배치의 거리·시간 이득, 칼날 피격/쿨다운, 투영의 전진·좌우 반응, 벽과 바닥 픽셀의 이동을 확인했다. 하드웨어 렌더러의 짧은 측정은 별도 JSON에 기록하며 최종 게임 전체의 성능 보장은 아니다.

## 벽·바닥 재질 교체 (2026-11-06)

현재 벽·바닥은 `sprite/topdown/terrain_v2/terrain.png`를 사용한다. 기존 1인칭 석회암 벽과 판석 바닥을 참고해 이미지 생성 도구로 재질 원본을 제작하고, SDL2에서 32×32 타일로 잘라 패킹했다. 벽 16연결형×재질 4변형과 바닥 8변형을 포함한다. 기존 Painter 시트는 보존하고 소품은 그 시트를 계속 사용한다.

벽 옆면·모서리 명암, 바닥 접촉 그림자, 시간대별 차가운 색조와 횃불 주변의 따뜻한 색조를 적용했다. 충돌·시야 판정과 맵 구조는 그대로다. 새 코드는 다음 실행부터 적용된다.

원본·생성 지시문·클립 좌표는 `sprite/topdown/terrain_v2`에, 실제 렌더링 비교는 `output/terrain_v2/06-comparison.png`에 저장했다. 비교 그림 왼쪽 아래는 연결·끝면 검토용 배치이며 최종 맵이 아니다. `python tools/build_terrain_v2.py`로 같은 타일 시트를 다시 패킹할 수 있다.

검사: 72개 타일의 좌표 범위·불투명 픽셀 확인, 기존 32개 미로 모델 검사 및 `main.py --smoke` 통과.

## 수호자 외형·배치 수정 (2026-11-06)

수호자를 `sprite/topdown/guardian_v2/guardian.png`의 64×64 방향별 대기 이미지로 교체했다. 현재 돌벽·바닥을 참고해 낡은 철갑·청동 원형 방패·철퇴 재질로 제작했다. 발 기준점을 맞추고 플레이어와 수호자를 발의 Y좌표 순서로 그린다. 기존 수호자 시트는 보존했다.

이름과 상시 체력 표시를 없애고 타격 직후에만 2.5초 체력바를 표시한다. 배치는 단순한 경로 19번째 칸 고정에서 분기·갈림길 선호로 바꿨다. 시작점·횃불·샘물·중앙 탈출구·숏컷 양끝과 통로 거리 4칸 이상 이격을 우선한다. 후보가 부족하면 이격을 완화하되 상호작용 칸에는 배치하지 않는다. 현재 32개 seed에서는 우선 이격 조건을 모두 충족한다. 기본 seed의 출구 B와 수호자는 통로 거리 9칸 떨어져 있다.

추적·순찰·공격 AI와 걷기/공격 애니메이션은 아직 구현하지 않았다. 이번 작업은 대기 외형·바닥 기준점·배치·표시 개선이다. `output/guardian_v2/01-real-maze-encounter.png`는 실제 시험 미로, `04-layout-review.png`와 `05-layout-detail.png`는 배치 검토용 장면이다. 재패킹은 `python tools/build_guardian_v2.py`.

## 숏컷 시트 적용 (2026-11-06)

사용자 선택안인 퍼즐형 1번 아치 돌문과 함정형 3번 무너진 벽 틈을 `sprite/topdown/shortcuts_v1`에 제작했다. 퍼즐형 닫힘·개방, 함정 입구·도착점의 정면·측면 총 8개 프레임을 포함한다. 생성 도구는 OpenAI 내장 이미지 생성이며 원본과 프롬프트를 보관했다. 투명 크롭·축소·패킹은 SDL2로 처리했다.

현재 게임의 함정 입출구 A/B를 무너진 벽 틈으로 교체했다. 그림의 문턱은 인접 벽에 붙이고 상호작용과 도착 좌표는 기존 바닥 칸을 유지한다. 지도·복귀·통과 규칙과 충돌 맵은 변경하지 않았다. 퍼즐 문은 시트와 렌더링 함수만 준비했으며 실제 퍼즐 UI·예약 개방은 아직 미구현이다.

`output/shortcuts_v1/01-trap-entry.png`와 `03-trap-arrival.png`는 실제 시험 미로, `05-layout.png`와 `06-layout-detail.png`는 시트 배치 검토용 장면이다. 전체 확대 시트는 `sprite/topdown/shortcuts_v1/sheet_preview.png`. 재패킹: `python tools/build_shortcuts_v1.py`.

## 기존 벽 기반 숏컷 v2 — 이전 제작안 폐기 (2026-11-06)

현재 사용하는 숏컷 시트는 `sprite/topdown/shortcuts_v2/shortcuts.png`이다. 위 v1 적용 기록은 폐기된 제작안의 이력이다. 주변 벽이 통째로 붙은 v1 시트·도구·미리보기는 활성 경로에서 빼고 `output/rejected_assets/shortcuts_v1`로 이동했다.

현재 벽 타일을 정확히 이어 붙인 원본을 이미지 생성 도구로 수정하고, 문·틈·얇은 테두리·작은 버튼 부분만 추출했다. 기존 벽은 그대로 렌더링하고, 새 부분을 보이는 벽 칸 안에만 적용한다. 벽과 같은 조명 계산을 사용하며 바닥에는 그리지 않는다. 상호작용과 충돌 맵·통과 및 복귀 규칙은 그대로다.

새 시트는 퍼즐 닫힘·개방, 함정 입구·도착의 4개 프레임이다. 방향은 해당 레이어만 90도 단위로 회전한다. 실제 퍼즐 동작은 여전히 미구현이다. `output/shortcuts_v2/07-before-after.png`는 실제 pico2d 렌더링의 v1/v2 비교다. 상태별 장면은 `06-layout-detail.png`, 실제 시험 미로의 입출구는 `01-trap-entry.png`와 `03-trap-arrival.png`다.

픽셀 검사에서 바닥 및 멀리 떨어진 기존 벽의 변경이 0임을 확인했다. 32 seed의 64개 배치 기준점과 함정 진입·정확한 취소 복귀·통과·지도 보존도 확인했다. 전체 프롬프트와 생성 원본은 새 에셋 폴더에 보관한다. 재패킹: `python tools/build_shortcuts_v2.py`.

## 실제 게임 배율의 숏컷 경계 수정 (2026-11-06)

현재는 `shortcuts_v2` 시트에서 생성된 주변 돌 테두리를 렌더링하지 않는다. 해당 테두리는 22픽셀 벽 윗면을 32픽셀 높이로 늘린 이미지라, 원래 벽과 돌무늬·선명도가 달라 실제 화면에 경계가 남았다. 이제 시트의 문 안쪽만 샘플링하고 테두리와 버튼은 원래 벽의 질감에 얇은 명암을 준다.

벽 연결형·재질 변형·문 상태·방향별로 32×32의 불투명 벽 타일을 한 번 합성해 캐시한다. 일반 벽과 같은 위치·필터·시간대/횃불 색상으로 그리므로 별도 투명 테두리가 확대되거나 주변 돌무늬를 덮지 않는다. 전체 화면을 흐리게 하는 후처리는 추가하지 않았다. 게임 재실행부터 적용된다.

`output/shortcut_seams/08-actual-scale.png`는 실제 1280×800 프레임에서 크기를 바꾸지 않고 자른 이전/수정 비교다. `01-trap-entry.png`, `03-trap-arrival.png`는 실제 시험 미로 화면이며 `05-layout.png`는 퍼즐 상태를 포함한 배치 검토 장면이다. 원본 배율의 합성 벽 타일은 `09-wall-tiles-native.png`에 있다.

검사: 96개 합성 타일의 편집 바깥 원본 픽셀 일치·완전 불투명·캐시 재사용, 최초/캐시 렌더링 동일성, 바닥·먼 벽 불변, 함정 진입/복귀/통과를 확인했다. 재현 명령은 `python tools/check_shortcut_tiles.py`와 기존 `python main.py --smoke`다. 실제 퍼즐 규칙은 여전히 미구현이다.

## 문 특징 복원 — 주변 경계 유지 (2026-11-06)

문틀을 없애 밋밋해졌던 퍼즐 문에 얇은 돌 아치·방사형 돌 이음새·꼭대기의 세 줄 문양을 복원했다. 닫힌 돌문은 중앙 이음선으로 문짝을 구분하고, 오른쪽 돌 버튼은 돌 면과 움푹한 경계로 표현한다. 개방 상태에서는 같은 아치 구조와 눌린 버튼을 유지한다.

문틀은 생성 이미지의 주변 벽을 되붙이지 않고 현재 벽 타일에서 원래 크기의 돌 질감을 가져와 구성한다. 기존 32×32 불투명 타일 캐시 방식과 벽 조명을 유지하므로 문틀 밖은 그대로이며 넓은 사각 패치는 없다. 함정 틈은 이번 수정에서 변경하지 않았다. 퍼즐 문은 표시 상태만 준비되어 있으며 실제 퍼즐 동작은 여전히 후속 구현이다.

실제 게임 프레임의 1:1 비교는 `output/door_detail/08-actual-scale.png`, 전체 배치 검토는 `06-layout-detail.png`다. 이 장면은 상태별 표현을 확인하는 검토용이며 실제 퍼즐 플레이가 아니다. 벽 바깥 픽셀·바닥 보존, 캐시 전후 일치, 96개 합성 타일, 함정 그림 불변을 검사했다. 게임 재실행부터 적용된다.

## 숏컷의 아치 문양·붕괴 표현 보강 (2026-11-06)

퍼즐형은 곡선 돌띠를 넓히고 이중 곡선 홈·방사형 돌 이음새·꼭대기 세 줄 문양을 강화했다. 문틀은 원래 벽의 돌 질감을 원래 픽셀 크기로 가져와 구성한다. 닫힌 문짝과 오른쪽 돌 버튼의 구분도 유지한다.

함정형은 돌이 빠진 비대칭 틈, 어긋난 상부 돌, 국소 균열, 입구에 남은 낡은 목재 보강재, 문턱과 바닥의 작은 돌 파편을 추가했다. 파편은 투명 배경의 별도 캐시 타일로 그려 바닥 배경을 통째로 덮지 않는다. 벽은 기존 불투명 합성 캐시를 사용하고 외곽의 넓은 사각 패치는 없다. 파편은 장식이며 충돌/상호작용 규칙은 그대로다.

실제 배율 비교: `output/shortcut_character/08-actual-scale.png`. 전체 배치 검토: `06-layout-detail.png`. `10-detail-zoom.png`는 디테일 확인용 2배 확대임을 이미지에 표시했다. 퍼즐 문 상태는 여전히 표현 검토용이며 실제 퍼즐 동작 구현은 아니다.

검사: 합성 타일 160개 중 파편 타일 32개의 투명 외곽, 원래 벽의 편집 바깥 픽셀 보존, 캐시 전후 같은 화면, 32 seed의 64개 배치 기준점과 함정 전환을 확인했다. 바닥은 파편 모양에 해당하는 픽셀만 바뀌고 다른 바닥/먼 벽은 그대로임을 검증했다. `python tools/check_shortcut_tiles.py`로 벽·파편 캐시를 검사한다. 게임 재실행부터 적용된다.
