## 현재 실행 범위

2026-11-25 기준, `main 8419529` 위 `feature/gameplay-restore-expansion`의 미커밋 작업본을 설명한다. 코딩의 모델·SDL 자동 검사와 총괄 독립 모델·프레임 확인은 통과 보고되었다. 숨김 Windows 창의 텍스트 입력 차단도 자동 검사했으며 사람 실키 플레이·소리 청취는 미실행이다.

일반 미로 탐색, 시간대별 지형 변형, 수호자 전투, 퍼즐 3종(마우스 미로·두 문양 석판 방·경로 선택), 1인칭 칼날방·여섯 줄 교차 돌방과 중앙 로프 F 탈출이 연결되어 있다. 본게임 돌방은 여섯 경사로가 연속되고 홀수 줄은 왼쪽→오른쪽, 짝수 줄은 오른쪽→왼쪽으로 돌이 구르며 중앙을 가로질러 정면 출구로 나간다. 후방 추격 방식은 별도 무적 연습에만 남긴다.

일반 미로는 기존 2D 격자 위에 쿼터뷰 바닥·벽·소품·함정방 입출구·수호자를 그린다. 플레이어는 이동 방향에 맞춰 대기·걷기·달리기·공격 시트를 재생한다. 발 위치와 벽의 지면 기준점으로 가림 순서를 계산한다. 함정방에 들어가면 마우스 좌우 이동으로 수평 360°를 둘러보는 1인칭으로 전환된다.

일반 미로는 캐릭터의 방향과 관계없이 플레이어 주변을 원형으로 밝힌다. 격자 기준 반경은 기본 5.5칸이며, 횃불을 얻으면 7칸으로 늘어난다. 벽은 뒤쪽 시야를 가리고, 새로 보이는 지형은 약 0.2초에 걸쳐 밝아진다. 현재 시간대에서 전에 확인한 지형은 어둡게 남는다.

## 실행

저장소 루트에서 실행한다. Python과 `requirements.txt`의 pico2d·transitions가 필요하다. Windows 맑은 고딕을 사용한다.

```powershell
python -m pip install -r requirements.txt
python -m SourceCode.main
python -m BoulderPractice.boulder_practice
```

일반 미로 창은 1280×800, 내부 화면은 640×400이다. 기본 시드는 117이다. `--seed`로 배치를 바꾸고, `--overview`로 전체 미로를 보거나 `--trap-preview`로 칼날방에서 바로 시작할 수 있다.

### 한 회차에서 함정과 퍼즐을 모두 체험하기

저장소 루트에서 다음 명령을 실행한다. 창 제목은 **2DGP | Test Course**이며 화면 상단에는 **검수 코스**가 표시된다. 시드 117을 바탕으로 고정한 전용 배치이며, 탐색 중이나 실패·탈출 후 **R**을 누르면 같은 낮·출발점에서 다시 시작한다. 일반 배치는 기존처럼 `--seed 117`로 실행한다.

```powershell
python -m SourceCode.main --test-course
```

지도 좌표는 (x, y), 거리는 미로 바닥을 걷는 칸 수다. 출발점에서 F로 횃불을 들고 아래 순서로 진행한다.

| 구간 | 위치와 조작 | 미로 보행 |
| --- | --- | ---: |
| 출발 → 칼날방 A | (3,1) → (8,1)에서 F. 칼날을 피해 정면 끝까지 가면 B (5,3)에 도착한다. | 5칸 |
| B → 여섯 줄 돌방 C | (5,3) → (2,3)에서 F. 중앙에서 입장 약 0.5초 후 정면을 보고 W로 걸으면 반대편 D (26,5)에 도착한다. | 3칸 |
| D → 마우스 문 | (26,5) → (23,5)에서 F. 시작점부터 1→2→3→도착 순서로 드래그한 뒤 다음 시간대를 기다린다. | 3칸 |
| 열린 문 → 석판 방 | 열린 (23,6)을 건너 (23,7)에 선다. (20,7)에서 F로 입장해 두 문양을 잇고 완성한 바닥을 걸어 건너면 (19,9)에 나온다. | 문 횡단 2칸 + 접근 3칸 |
| 석판 출구 → 경로 선택 | (19,9) → (22,9)에서 F. 카드 한 장을 고르고 확정한다. 다음 시간대에 선택한 문이 열린다. | 3칸 |
| 선택문 → 합류 → 중앙 | 1번 문 (24,10) 또는 2번 문 (26,10)을 지나 (18,17)에 합류한다. 중앙 로프 (15,11)에서 F로 탈출한다. | 합류까지 16칸 또는 20칸 + 중앙까지 9칸 |

시간대는 60초마다 바뀐다. 함정 피격과 수호자, 일반 미로의 우회로도 동작하며 세 퍼즐은 자유롭게 건너뛸 수 있다. 1번은 수호자 (24,13) 앞을 지나는 짧은 길, 2번은 벽 뒤로 도는 긴 길이다. 30/60/120Hz 자동 보행에서 1번은 발견·추격·공격 후 15 피해, 2번은 발견·피해 없이 통과했다. 칼날의 20 피해를 포함한 탈출 HP는 각각 65와 80이었다. 수호자는 기존 전투와 이동 판정으로 동작한다. 같은 과정을 SDL 입력으로 재검사하려면 `python -m TestCode.check_demo_course`를 실행한다.

| 입력 | 현재 동작 |
| --- | --- |
| W / A / S / D | 일반 미로에서 통로 방향 이동. 화면에서는 각각 북서 / 남서 / 남동 / 북동 |
| Shift + 이동 | 달리기·스태미너 소모 |
| 마우스 좌클릭 | 일반 미로에서 화면 8방향 단검 2연타 |
| 좌클릭·드래그 | 마우스 미로 경유지 1→2→3 연결 / 석판 방 조각 집기·놓기 |
| 경로 선택 카드 클릭 → 확정 버튼 | 후보 미리보기 → 이번 회차의 한 경로 예약 |
| F | 횃불·샘물·함정방·퍼즐·중앙 탈출구 상호작용 / 교차 돌방 정면 출구 이용 |
| M | 현재 시간대 방문 지도. 플레이어 이동은 멈추고 세계 시간은 계속 진행 |
| V | 전체 미로 검사 보기 전환 |
| R | 새 회차·스폰 변경·시작 시간대 낮→밤→새벽 순환. 석판 방에서는 선택/들고 있는 조각 90° 회전 |
| F10 | `output/topdown/manual.png` 저장 |
| Esc | 지도·퍼즐 닫기 / 함정방 원위치 복귀 / 탐색 중 종료 |
| 함정방 마우스 좌우 이동 | 수평 360° 시선 회전. Q 후방 보기 제거 |
| 함정방 W/S, A/D | 현재 시선을 기준으로 전진·후진·좌우 이동. Shift 달리기 |

일반 미로에서 서로 다른 축의 두 키를 함께 누르면 격자 기준 대각선으로 이동한다. 반대 방향 키는 서로 상쇄된다. 걷기와 달리기는 화면에 투영된 지면 거리에 맞춰 속도와 보행 프레임을 계산한다.

좌클릭 한 번으로 시작 방향을 향해 베고 되벤다. 750ms 동작의 233ms와 466ms에 각각 앞쪽 1.8칸 이내 수호자를 확인해 피해를 준다. 벽이 사이에 있으면 해당 타격이 막히며, 다음 공격은 동작이 끝난 뒤 시작할 수 있다.

수호자는 벽에 가리지 않은 6칸 이내에서 플레이어를 발견해 통로로 추적한다. 가까이 오면 머리 위에 `!`를 띄워 공격을 예고한다. 예고가 끝날 때 1.25칸 이내이고 벽이 사이에 없으면 피해 15를 준다.

함정방과 독립 돌 연습은 창이 포커스를 얻으면 마우스를 캡처하고, 포커스를 잃거나 방에서 나오면 해제한다. SDL 텍스트 입력 중지와 Windows IME 연결 해제를 적용했다. 숨김 Windows 창의 자동 검사에서 W 키 이벤트 5개는 유지하고 문자 이벤트는 5개에서 0개로 차단했다. 사람이 직접 한/영 전환·포커스 복귀를 조작하는 플레이 검수와는 구분한다.

### 시간대와 퍼즐 3종

낮 → 밤 → 새벽 순으로 각 시간대가 60초 동안 이어진다. 5초 전에 전환을 예고하고, 지형을 바꾸는 동안 플레이를 잠시 멈춘다.

| 퍼즐 | 조작·완료 | 결과 |
| --- | --- | --- |
| 마우스 미로 | 13×9 통로에서 출발 → 경유지 1→2→3 → 도착 순으로 드래그 | 다음 시간대에 문 개방 |
| 두 문양 석판 방 | 4×4 바닥에 직선 3개·모퉁이 6개를 배치하고 R로 회전. 입구→두 문양→출구 연결, 문양 순서는 자유 | 조립 후 WASD로 반대 끝까지 직접 걸어 나가면 즉시 외부 반대편 도착 |
| 숏컷 경로 선택 | `1번 통로`·`2번 통로`의 실제 거리와 기준 노출 수를 비교해 하나 확정 | 다음 시간대에 선택한 통로만 개방 |

마우스 미로는 벽·모서리 가로지르기를 막고 마지막 유효 위치에서 멈춘다. 버튼을 놓았다가 이어 그릴 수 있으며, 되짚으면 경로와 경유 진행도 함께 되돌린다. 경유지를 순서대로 지나지 않고 도착한 경우 완료되지 않는다. 미완료 경로는 같은 시간대에 이어 풀 수 있고 전환 때 초기화된다.

마우스 미로·경로 선택 패널과 방문 지도를 열어도 세계 시간과 수호자는 진행하며 피격되면 닫힌다. 석판 방에서는 시간은 흐르지만 외부 수호자는 갱신하지 않는다. 조립만으로 예약·순간이동하지 않으며, Esc·후퇴·시간대 전환은 입장 전 위치로 복귀한다. 직접 통과한 방은 같은 회차에 양방향으로 재이용할 수 있다.

경로 후보는 시드·회차의 지형에서 탐색한다. 조건에 맞는 두 후보가 없으면 경로 선택을 배치하지 않는다. 표시된 노출 수는 현재 수호자 위치와 예정 지형 기준이며 수호자가 움직이면 바뀐다. 항상 안전하거나 모든 회차에 생성된다는 보장은 없다. 거리 비교는 칸 수이며 퍼즐 조작·대기·전투를 포함한 시간 단축을 뜻하지 않는다.

### 함정방 숏컷

확정 규칙은 **퍼즐로 막힌 길 개방, 함정방 통과로 길 단축**이다. 칼날방 A를 끝까지 통과하면 B로, 여섯 줄 교차 돌방 C를 지나 정면 출구를 통과하면 D로 이동한다. 연결 출구는 중앙까지 남은 탐색을 보존하는 외부 통로에 둔다. 함정방의 무기 지급·보상 획득 기록은 사용하지 않는다.

Esc 중도 취소와 시간대 전환 때만 입장 직전의 정확한 외부 좌표·방향으로 복귀한다. 사망은 실패이며 본게임 돌 접촉은 즉사다. 독립 후방 추격 연습은 무적이다. 총괄 모델 검수에서 양 함정의 정확한 취소 복귀·정상 B/D 착지와 보상 기록·문구가 없음을 확인했다.

캐릭터·셀·아이콘 에셋 교체는 보류 상태다. 새 무기 종류·외형과 보스·중앙 안내는 이번 작업 범위 밖이며, 목표 기획은 [PRD](Docs/PRD.md)와 구분해 관리한다.

## 에셋 연결

- 플레이어는 `sprite/quarter/player_explorer_attack_v2/`의 `explorer.png`와 `explorer.json`을 사용한다. 이동 중 공격은 `moving-attack.png`의 상체와 다리 프레임을 합성한다. 검격 효과는 재생 중인 프레임의 단검 칼끝에 맞춰 그린다.
- 지형·소품·수호자·함정방 입구는 각 `catalog.json`의 프레임과 지면 기준점을 사용한다. 이번 변경에서 셀·아이콘·캐릭터 에셋을 교체하지 않았다.
- 마우스 미로 패널은 `sprite/ui/mouse-maze-panel.png`를 사용한다. 통로와 벽은 기존 석재 재질로 그린다.
- 독립 후방 추격 연습은 `sprite/traps/boulder_room_v2/catalog.json`의 `props`와 `exits`를 읽는다. 본게임은 `six_lane_trap.py`·`six_lane_view.py`의 교차 경사로와 공용 석재·돌 재질을 사용한다.
- `sprite/traps/boulder_chase_v1/catalog.json`은 **먼지 전용**이다.
- 1인칭 벽·바닥·천장 원본 재질, 회전 돌 재질, 칼날, 불꽃·검격 효과, 효과음은 재사용한다.

```powershell
python -m TestCode.check_first_person_movement
python -m TestCode.check_shortcut_choice
python -m TestCode.check_boulder_integration
```

규칙 검사는 시선 기준 이동, 후보의 통행·선택문 개방·회차별 생략, 정상 완주의 연결 출구 이동·중도 정확 복귀·사망·회차 초기화를 확인한다. 기존 퍼즐 검사는 경유 순서, 두 문양 연결·실제 보행, 예약 개방과 시간대 경계를 확인한다. 코딩은 `SourceCode.main --smoke`가 실행하는 `check_game_render` 전체 SDL 회귀, 독립 Practice 스모크·`check_corridor_isolation`·`check_visuals`·`check_six_lane_render`를 통과했다. 더미 SDL 검사와 숨김 Windows HWND 자동 입력 검사는 사람의 실키 플레이·소리 청취·체감 성능 평가를 대신하지 않는다.
