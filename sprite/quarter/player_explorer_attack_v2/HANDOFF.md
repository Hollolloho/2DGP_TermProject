# 플레이어 8방향 단검 2연타

`feature/coding`의 `669c394`에 있는 탐험가를 기준으로 삼았다. 얼굴·머리·복장 파츠는 원본 방향별 프레임에서 분리했다. 옆모습 등에서 가려진 일부 사지는 같은 방향의 원본 보행·공격 프레임을 사용했다. 단검은 기존 동쪽 베기에서 분리해 모든 방향에 같은 크기로 사용했다.

## 게임 시트

`explorer.png`는 512×2240 RGBA 시트다. 공격 클립 외의 셀은 기존 아틀라스의 픽셀을 보존한다. 각 동작은 화면 기준 `attack-n`, `attack-ne`, `attack-e`, `attack-se`, `attack-s`, `attack-sw`, `attack-w`, `attack-nw`로 찾을 수 있다.

- 각 클립은 64×64, 공통 발 기준점 (32,54), 13프레임, 750ms, 비반복이다.
- 프레임 시작은 0, 70, 150, 233, 275, 333, 376, 418, 466, 516, 572, 642, 700ms다. 네 번째와 아홉 번째 프레임이 시작되는 233ms와 466ms에 `hit` 이벤트가 있다.
- 첫 베기의 회수 자세에서 단검을 다시 들어 반대 방향으로 되베고 중립 자세로 돌아온다. 두 번째 베기까지 두 발의 위치를 고정하고 572ms부터 중립 자세로 발을 옮긴다.
- 시작과 회수가 끝난 700ms에는 해당 방향의 대기 첫 프레임을 사용한다. 단검이 보이는 동안 칼끝은 앞쪽을 향한다. 준비와 회수 사이 손목의 각도는 달라지며, 각 방향의 팔꿈치는 같은 쪽으로 굽힌다.

## 검격 효과

`sprite/quarter/effects/dagger-slash.json`의 `tip_px`는 13개 신체 프레임 각각의 칼끝 위치를 64×64 프레임 좌상단 기준 논리 픽셀로 담는다. 첫 검격은 200–400ms에 재생된다. 같은 효과를 233ms 뒤인 433–633ms에 다시 재생해 두 번째 검격을 표시한다. 두 효과의 세 번째 프레임은 각각 233ms와 466ms에 칼끝에 닿는다.

8방향의 두 타격 프레임에서 단검이 보이고, 표시된 칼끝 픽셀은 리그 좌표의 1px 이내에 있다. 남쪽 모션에서 팔꿈치는 두 타격 뒤에도 어깨보다 아래에서 몸의 같은 쪽에 머문다.

## Spine 편집과 내보내기

`spine/explorer-attack.spine.json`은 Spine 4.2.22 가져오기 형식을 사용한다. 본 11개, 슬롯 9개, `spine/images/`의 분리 PNG, 공격 키프레임 8개 방향을 포함한다. 기본 셋업은 단검을 든 남서 방향이다. 각 방향의 애니메이션을 고르면 해당 방향의 파츠와 포즈가 로드된다. [Spine JSON 형식](https://en.esotericsoftware.com/spine-json-format)

Spine에서 **Import Data → New project**로 JSON을 열고, 이미지가 누락되면 **Images → Path**에 `./images/`를 지정한다. 가져온 프로젝트를 JSON 옆에 저장하면 이미지 상대 경로를 유지하기 쉽다. 현재 환경에는 Spine 편집기가 없어 실제 가져오기와 네이티브 `.spine` 저장 및 편집기 내보내기를 확인하지 못했다. [Spine 가져오기 안내](https://en.esotericsoftware.com/spine-import)

게임용 셀을 만들 때는 본 원점을 프레임의 (32,54)에 두고, 방향별로 위 13개 시점에서 64×64 투명 프레임을 샘플링한다. 공통 캔버스를 유지하고 `explorer.json`의 방향별 `rect`에 배치한다.
